## 司令部反馈执行记录

1. 主方向由第三张锁定；不重新设计全局风格。场景布局取第二张的清晰战斗空间，材质取第一张选择性的潮湿与破败细节，不把第一张整套写实渲染搬回。
2. Skeleton 强化功能性墓葬连接，不靠盔甲、绿眼或满身发光刻纹识别。近景板为结构设计依据；场景缩小版不能要求看清每根绳与钉。
3. Remains 保留连接，局部骨端有趋向解剖位置的微弱关系；实际微动、暂停与再次牵引尚未制作。禁止整堆悬浮、明亮牵引网和满屏粒子。
4. Loot 初稿工具仍偏大，完整保留为 loot_scale_v1.png；新版本缩小并降低存在感。世界小图负责尺度，底部放大图只供检查形体，不代表放大后的世界尺寸。
5. Sigil 由词义形成结构；保持词完整可读。OBSERVE 的对焦轴线、SHATTER 对应破边、ERODE 非均匀损失各不同。场景中的缩小 Sigil 仍是概念占位表达，具体几何以独立 Sigil 板为准；正式接入时必须以独立可编辑几何和真实字体实现，不能从整张场景图裁切充当按钮。
6. 左上 HUD 暂沿用，未进行重新布局或改机制。数值只是图像占位，无运行状态绑定。
7. 标志物确定为旧铁书页扣件，常态暗哑，响应仅一条细缝短暂对齐；近景板是放大检查，不是游戏中的饰物尺寸。背侧镜头可能遮挡胸前扣件，不应为让它可见而放大或穿透衣物。
8. 未制作 Ghost、Wraith、Boss 或后续场景。未制作新玩法、掉落规则或程序机制。

## 素材与可编辑源

本目录保存六张原始 PNG、六份完整实际调用提示词、参考链和校验信息。早期图均保留，没有覆盖第一轮或本轮初稿。源目录被已有 art_source/.gdignore 排除 Godot 导入，仍受 Git 管理。

当前可编辑的是设计说明、提示词与尺度要求；图像生成器未返回分层 PSD/KRA 或骨骼工程。本轮不声称已经提供分层生产源。后续拆层与动画源进入 art_source/，独立运行导出进入 assets/art/；环境、角色、绳/骨件、雾、Echo、Loot 高光和 Sigil 分开。

基准图为 1672×941（接近 16:9），非项目原生 1280×720；结构板为 1536×1024。当前没有假称像素级相同的最终游戏尺度。制作前需要以真实摄像机和单位换算统一画布/锚点。

来源：OpenAI 内置 image_gen；仅用户 Visual Bible 与本项目生成图作为输入，未引入第三方图片、字体或音频文件。工具未公开精确模型版本或 seed。完整正向及禁止项在 *.prompt.txt，实际引用文件在 manifest.json。商用条款及外发授权未核验，本轮不上传 GitHub。
