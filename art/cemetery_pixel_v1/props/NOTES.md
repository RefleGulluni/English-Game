# Props：原点、占地与碰撞交接

地面逻辑格 32×32；下列为美术建议，精确碰撞由 Claude 在 Godot 验证。所有 PNG 的原点为图片底边中心 `(W/2,H)`，左上为 `(0,0)`。透明留白是原点契约的一部分，不要自动裁切。

Sprite2D 使用 centered=true 时可设 offset=(0,-H/2)，把 Node2D 放在地面接触点；不需要非整数缩放。Y-Sort 使用这个根节点。

| `tombstone_upright_01.png` | 72×77 | (36,77) | 2×1 | (-32, -15, 44, 15) |
| `tombstone_tilted_01.png` | 72×76 | (36,76) | 2×1 | (-32, -18, 48, 18) |
| `tombstone_fragment_01.png` | 64×35 | (32,35) | 2×1 | (-24, -28, 48, 28) |
| `open_grave_01.png` | 128×72 | (64,72) | 3×2 | (-40, -64, 96, 64) |

- 树仅树干/根脚阻挡，树冠参与遮挡；长根可作为视觉延伸，不必全做碰撞。
- 墓碑占地按包围底座向上取整，碰撞可比格子占地更紧。
- 倒碑碎块为低矮物件；可按房间设计决定是否阻挡，不能因画布较宽而自动铺满碰撞。
- 墓穴底座 3×2 格（96×64），图像多出的高度用于破损边沿/残碑。坑洞内部应阻挡或按设计处理，不当作普通泥地。
- 墓穴矩形可偏离原点对称，这是 3/4 视角与底部接触点共同导致的正常偏移。
- 无物件烘焙投影；接触阴影、光色、Y-Sort、雾和最终碰撞由 Godot 统一提供。

## 实机确认后的底座补充（当前执行）

地面采用整张 `plates/ground_plate_960x540.png`，所有高物件独立；下面的 base 属于**平面地面贴花**，不是物件投影，也不增加碰撞。

叠放顺序：**地面板 → base / 枯草贴花 → 角色与高物件**。Base 永远低于所有角色脚底，不加入角色/高物件的 Y-Sort。不要因为树的根节点参与 Y-Sort，就让 base 继承相同排序；base 应单独放到地面装饰层。

每一对 prop 与 base 的**世界原点完全相同**，均为各自 PNG 的底边中心 `(W/2,H)`。部分 base 画布更宽，用于容纳翻土；不要将两张图片按几何中心叠放。使用 Sprite2D centered=true 时，两张图各自设 `offset=(0,-H/2)`，节点位置使用同一个世界坐标，即可原生 1× 对齐。禁止自动裁切透明留白。

### 枯树修订

- `dead_tree_01.png` 画布仍为 288×224，原点仍为 (144,224)，上部树冠/树干像素保持原样。
- 原图 y=160～223 的根部移到 base；高物件保留 y=0～177，y=160～177 与 base 有 18 行重叠，确保树干扎入根部而不是断开。
- 最前端 y=214～223 的根尖由底下的生成湿泥覆盖，形成入土的末端；这不是渐变透明或漂浮根须。
- 高物件下部的透明区是刻意保留的原点空间。**修订后的树必须与 base 配对使用**，不要把高物件底部非透明边缘重新当作原点。
- 高物件与 base 的重叠像素颜色相同，不新增固定地面投影。原有接触阴影仍可由 Godot 统一处理。
