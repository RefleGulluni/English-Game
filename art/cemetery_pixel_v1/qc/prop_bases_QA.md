# 底座贴花与独立枯草补充 QA

**交付：5 块 base、4 块独立枯草、修订枯树高物件、叠放预览。技术像素检查通过，等待 Godot 实机确认落地感。**

以实机结论为准：整张地面板 + 独立高物件。所有 base 和新增枯草均为地面贴花，放在地面板之上、所有角色脚底之下；不参与 Y-Sort，不提供碰撞。

## 实际尺寸与颜色

逐文件尺寸、颜色数、Alpha、包围盒、原点与 SHA-256 见同目录 `prop_bases_QA.json`。物件与 base 的对应表见 `props/NOTES.md` 和 `props/ground_bases.json`。

- Base 画布：树 288×224；直立碑 96×77；倾斜碑 104×76；碎碑 96×48；墓穴 176×80。
- 枯草画布：20×10、28×14、36×18、48×24，各 1 张，四种形状独立生成，不是同一张缩放复制。
- 本轮全部素材使用现有 `cemetery_palette.gpl`，未修改、未扩充调色板；可见颜色并集为 62。
- 所有素材为原生分辨率 RGBA PNG。Alpha 只有 0/255；调色板外颜色为 0；采用 nearest 原生规整，无抗锯齿、无渐变透明、无抖色。
- `prop_bases_preview.png` 为 2880×1940（2× nearest）；`tree_root_contact_4x.png` 为 1152×640（4× nearest）。预览底图取自实际交付地面板。

## 落地关系与枯树修订

五张底座均有实际翻土、压痕、短枯草等材质，未采用投影椭圆。墓穴底座的长轴与墓穴一致，碎碑底座沿倒碑方向形成浅槽。

枯树保持原画布和原点。原根部 y=160～223 转移到 base，高物件只保留 y<178 的树冠/树干。18 行交叠区共有 1221 个重叠实心像素，颜色完全一致，叠放无透明断层。原树上部 y<160 的像素逐项不变。

最前端 10 行中，65 个旧根尖像素被湿泥覆盖或隐藏，让根尖进入地面。除此之外没有意外丢失或改色的原树像素。底座泥土取样范围为 156×72，比被转移的贴地根展开范围略大。

两张 PNG 画布尺寸不同时，以各自 `(W/2,H)` 对到同一个世界坐标；不是把图片中心叠在一起。预览按此规则绘制，未做运行时缩放补偿。

## 检查边界与已知限制

- 这是静态美术叠放验证，没有修改 Godot 工程、场景或灯光；最终落地感、角色遮挡和缩放需 Claude 实机复核。
- Base 不含方向性投影。湿土暗色属于地表材质，不是烘焙阴影；统一接触阴影仍由 Godot 处理。
- 树的原点空间保留在高物件透明下部；单独显示修订后的高物件会缺少贴地根，必须与 base 配对。
- 泥土与地面板明度接近，连接应当克制。若放进大片积水中，土会表现为被翻起的较干土岛；常规摆放优先选泥地区域。
- 本轮仅修改已有 `props/dead_tree_01.png` 和 `props/NOTES.md`；其余已有素材、调色板和旧 QA 快照均保持原样。
