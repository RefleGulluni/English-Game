# Skeleton B turnaround provenance

Only three new direction sprites were added. The approved front PNG, Bone Remains, A/C designs and all old source/QC files were left unchanged and hash-checked.

One complete figure was generated per direction attempt using built-in image_gen. The chosen left source unexpectedly includes an extra front draft; only native x=[0,28) is used, and the generated extra front is NEVER a standard. Each recorded grid cell is sampled at its single center pixel. Material colors map only to the48RGB union of approved B front and remains. No random texture or new RGBs.

The selected back and right samples were107rows tall. Native anatomical length editing omits explicit hand-selected source rows at neck/torso/long-bone segments to align to96px standard; this is recorded rather than claiming the generator met dimensions. Source_row_lookup and integer registration reproduce the output exactly. No whole-image resize/interpolation, mirror or rotation is used for game pixels.

The scripts are historical recipes. Their W workspace is archived after delivery at `/Users/mac/.Trash/english-game-skeleton-directions-working-20261025`; sources also exist in sibling direction folders. Only reference/QC enlargement uses integer NEAREST. Neither runtime scenes nor animations are part of this delivery.
