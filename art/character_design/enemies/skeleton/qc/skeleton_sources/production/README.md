# Skeleton design exploration provenance

All six game sprites originated from individually generated large-square pixel art using built-in image_gen. High-resolution concept references were generated separately AFTER the native sprites; those illustrations were never sampled into game art.

See each sibling source folder for full chosen source, exact cell-center recovery, grid boundaries, native selection cleanup, final sprite and checker output. Pair palette colors are actual sampled source RGB representatives; no dithering or random texture was added. Bone piles use hand-selected integer translations to tuck loose bones inward. The B upper17-row head/neck/pin-tip selection settles1px toward shoulders; no waist cut or global sprite resize.
