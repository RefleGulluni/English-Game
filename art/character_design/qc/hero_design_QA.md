# Wordbearer 主角外观四方向 · QA

日期：2026-10-23。范围：静态角色外观设计；尚未进入 Godot 组装或实机验证。

## 设计说明

- **A｜磨损的幸存者**：短披肩、收拢的层叠衣物与旧靴保留原主角的疲惫感，以贴身的小型撬具替代长剑，肩部形成略宽的轮廓。Lexicon 是胸前固定披肩的青蓝小扣件。
- **B｜记录世界的旅人**：长外套形成纵向轮廓，鼓起的挎包露出笔记页与纸卷，手提一盏没有发光的旧灯。Lexicon 是包盖上的小型节点扣饰，青蓝仅出现在这里。
- **C｜学者型幸存者**：短背心、浅色卷袖、缠绷带的手与细瘦的腿构成较轻的轮廓，短铁棍仅作为应急工具。腰侧破损的书就是 Lexicon，青蓝落在书封扣件上。
- **D｜车站的遗留者**：旧铁路制服帽、残损短制服与沉重工作靴留下职业生活的痕迹，帽檐和较方正的上身区别于其他三案。Lexicon 是胸袋边夹着的票片式小器物。

- 已逐张查看最终角色与四案剪影：站立、朝画面右下、可见头顶和肩上表面的 3/4 俯视；成人比例，低饱和，轮廓分别强调短披肩、长外套、腰挂书和制服帽。
- 角色透明背景，无抗锯齿、无连续渐变、无地面及烘焙投影。没有为微光添加半透明光晕；微光由物件上的明亮青蓝实体像素表达。
- 世界实体颜色全部映射到 `art/cemetery_pixel_v1/cemetery_palette.gpl`。该调色板明确不含语言青蓝，本批独立允许 Lexicon 使用 `#248B9B / #46CAD5 / #A4EDEF`，最终实际使用 `#46CAD5`；其他衣物、皮肤及灯具均没有使用这组颜色。
- 四张 PNG 使用相同底边锚点 **(48, 96)**，脚尖/鞋底最低像素到达第 95 行。两靴底部九行的外缘中点因离散像素分别为 47.5 / 48 / 48.5 / 48，最大小于一个像素的取整差；未移动到半像素坐标。
- `hero_design_compare.png`：四人并列放在已有墓园地面板的同一连续裁切区域上，角色和地面先按原生像素合成，再以 nearest 放大 4 倍；角色可见高度均为 **384 px**，整图 **2560×720**。地面仅用于 QC，来源为已有 `art/cemetery_pixel_v1/plates/ground_plate_960x540.png`，没有制作或修改场景资产。
- `hero_design_silhouette.png`：同位置、同倍率的纯黑角色剪影，浅灰底，无投影。
- 使用内置 image_gen 分别生成四张原图，再做透明阈值、nearest 缩图、限定调色板及底部对齐；Lexicon 采用覆盖率保留，避免缩小后青蓝细节丢失。生成提示词见 `hero_design_prompts.json`，实测数据及原图路径见 `hero_design_metrics.json`。
- 没有修改任务开始前的素材、代码或 Godot 配置。仅新增 `art/character_design/` 下的交付文件；仓库中其他已有改动不属于本任务。
