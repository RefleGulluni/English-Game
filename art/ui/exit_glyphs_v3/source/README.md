# 出口符号 v3 原生来源

9个15×15白色透明PNG，共用下方门槛，与已通过11×11词类同一套1px整数几何语法。这里的脚本只在本新目录导出素材和QC，不写任何运行时或旧素材。

- `build_exit_glyphs.py`：逐点定义路径、导出成品／检查图／截图副本。
- `exit_geometry.json`：完整路径、共同门槛、坐标和点阵。
- `exit_rows.json`：和PNG完全一致的大写名称X/点行表；COMBAT文件对应规则层encounter，UNKNOWN是尚未理解的显示，不是独立路线节点。
- `protected_files.json`：已有词类PNG／共享QA、出口脚本、源截图的保护哈希。
- `before_*.zip`：内部修改前的脚本／输出恢复记录，不是另交多套方案。

运行时请原生15×15、最近邻采样，语言层按需要染色／发光／浮动；不要镜像、裁掉透明外圈或把本体重新缩放。检查板的标签用系统字体绘制，未复制系统字体进仓库。新符号没有烘焙光晕。

截图合成点(898,56)只用于尺寸检查，不是实际出口逻辑坐标。重跑或改图后应重新检查和更新手写QA。
