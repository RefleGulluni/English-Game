## 2. 做法：保留材料层次，不回到4色底子

使用内置image_gen，所有提示词和生成原图在`source/`。先生成细格子、冷湿泥地，包含较大的湿暗/稍干起伏与小泥纹。按源图行列变化定位格边，每格取一个整数中心点；`01_grid.json`、`01_grid_overlay.png`、`01_restored_cells.png`保留坐标与结果。未整体resize、平滑或取平均。局部网格漂移仍可能存在，未声称每格都人工精确校正。

原生裁切后，无抖色合并为40色，再把面积≤3、颜色距离≤18的碎色并入相邻、已经更常见的同类泥色，两轮处理。合并方向固定，避免相邻碎色彼此交换而没有变安静。换色率从约94%降到约66%，仍有40色，不再把整个泥地压成四档。

主要颜色含义：冷暗灰褐是湿泥低洼；稍亮灰绿褐是压实、稍干的土面；少量暖赭是松散黏土；冷灰蓝的短小亮片是微弱湿反光。大起伏与细纹都保留下来，但一些细颗粒仍不能逐点确认含义，尤其反光/泥脊形成较容易识别的弯曲结构，是本轮未解决的问题。

## 3. 首尾相接如何修

1. 将原生224×128图左右移112、上下移64，把原来的边缘移成中间十字；保留`03_half_offset_native.png`及6倍图。
2. 用该偏移图作输入，内置image_gen只修中央十字，尽量延续湿泥和压实土面；原图为`04_seam_repair_generated.png`。
3. 编辑图保留输入的224×128逻辑布局，按注册格边各取一个中心点还原，坐标在`04_grid.json`，叠图及局部检查保留。生成输出尺寸与输入显示图不同，**恢复的是格子，不是用插值把整图缩小**。仍有局部格边偏移的可能。
4. 用共同40色材料表匹配编辑图，并同样整理碎色。中间采用**不规则最小色差切线**，在原图和编辑图的已有像素之间选取，避免直矩形补丁；无混色、模糊或程序合成新纹理。切线和掩膜在`05_seam_assembly.json`、`05_repair_selection_mask.png`。
5. 最外1像素采用已有泥地的细纹颜色轮廓，将相对两边配成相同值；角点一致。**没有画同色边框**。这保证数字接边，不保证整屏看不出重复。

变体02以01为输入，另做内区编辑，移动/打散中心较醒目的湿暗凹块、调整湿干区域。用原生已有像素、同一颜色表和不规则切线装回，保留外圈。四边及外8像素与01相同；原图、网格、选择掩膜和记录在`07_*`、`08_*`。

## 4. 裸铺检查与仍未解决的问题

裸铺采用种子1048，01/02随机、不旋转、不镜像。拼5×5块后原生裁出960×540，再最近邻2倍；随机ID表在`08_variant_assembly.json`。没有为检查图单独修补接缝或摆贴花。

**改善：** 对比32×32，材料不再只有均匀细颗粒，冷湿色与较大明暗起伏有了；中间十字的直切感已减弱，外边数字相接，未再出现整齐的暗框。

**未过关：** 主底子的湿暗凹块和弯曲反光带仍有可辨认形状；变体更换内区后，共用边缘周围的结构和部分中心轮廓仍反复出现。裸铺能找到224×128节律。局部修补处纹理密度也不完全相同，不能宣称所有视觉接缝已消失。

又做了一次一对一材料色表调整，压暗并降低反光对比，原40色因整数取整合并为39色，没有改几何、加噪点或模糊。`09_final_palette.json`记录全部前后RGB。**当前`base_fill_2x.png`就是降对比后的版本，重复依然能认出**；调整前版本是`base_fill_before_contrast_2x.png`。继续单纯压对比会损失需求要求的湿泥材料层次，因此没有把“变平”当作修好。

可复查：`base_01_only_fill_2x.png`（仅主底子）、`base_center_repair_8x.png`（修缝局部）、`base_wrap_junction_8x.png`（01/02交界）、`repair_grid_detail_3x.png`（编辑图格边）。最小色差切线和边缘一致都只是过程检查，不能替代核心裸铺标准。
