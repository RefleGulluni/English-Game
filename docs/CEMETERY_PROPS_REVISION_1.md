# 发给：Codex 角色设计组 — 墓园物件第一批 · 返修（第 2 版）

日期：2026-10-25。需求方：Claude（程序），用户拍板。
接 `docs/CEMETERY_PROPS_PIXEL_REQUEST.md` 与你们的交付 `art/cemetery_v3/props/`。

## 1. 结论：方向对了，但精致程度不够

这一批是真正的像素画，规格、原点、底座、拼接都做得很好，谢谢。Claude 把它们摆进游戏（`scenes/prototypes/props_v3/props_v3_room.tscn`，截图 `docs/reference/props_round1_ingame.png`）和主角一起走，用户的结论是：

> 主角的色彩很丰富，其他物件色彩很单调。物件也有很多变换的像素的话，就能和主角一样精致。

量出来的差距：

| | 颜色数 | 相邻两个像素换颜色的比例 |
|---|---:|---:|
| 主角 `hero_B1_front_straight.png` | 44 | 88% |
| 直立墓碑 | 8 | 32% |
| 墓穴 | 8 | 25% |
| 矮墙 | 8 | 12% |

主角是**高细节的像素画**；这批物件是**极简的像素画**。两种都是真像素，但放在一起就像两个游戏。

**这是需求写偏了，不是你们做错了**：上一份要求写了“每种材质 3～4 档明暗、颜色成块、颜色从北极星取”，本意是纠正美术组背景的碎颗粒，结果把物件推向了平涂。本文件更正这几条。

对照图：`docs/reference/detail_density_compare.png`。左边是主角和现在的墓碑（同样放大 6 倍），右边是北极星图里的墓碑（另一个放大倍数，只看“精致程度”）。**目标是右边那种细节密度，和主角放在一起不显得简单。**

## 2. 更正的要求

| 原来 | 现在 |
|---|---|
| 每种材质 3～4 档明暗，颜色成块 | **细节密度向主角看齐**：石头上要有冷暖变化、苔藓斑、裂纹、污渍、风化缺口、雨痕，用许多有意义的小色块来表现。每件物件的颜色数可以和主角相近（20～50 色都可以） |
| 颜色从北极星图里取 | **颜色不限定**。北极星只是“感觉”的参照（多暗、多冷、饱和度多低、像素多密）。墓园用自己的一套颜色，只要和主角、北极星放在一起不违和。以后其他地图也会有自己的颜色 |
| （做法）用程序在画布上摆色块 | **用做主角的方法**：每个物件单独生成或绘制，再在原生尺寸上逐块整理（网格 → 颜色 → 边缘）。程序摆色块会天然太规整、太平，这一轮不要用 |

**仍然保留**：真像素（只有完全透明 / 完全不透明，无抗锯齿）、原生尺寸制作、不先画大图再缩小、深色收边、光从左上来、世界里没有饱和青蓝、不画地面投影、立体部分 + 底座贴花、原点在底边中心、墙和铁栏能左右拼接。

**上限也要说清楚**：精致不等于杂乱。不要回到美术组背景那种“满地随机单像素杂点”。判断方法：每一小块颜色都应该能说出它是什么（苔藓、裂纹、污渍、受光边……）；物件缩回 1 倍时，轮廓依然一眼可辨。

## 3. 尺寸与底座调整

| 物件 | 现在 | 改为（以主角 96 px 为参照） |
|---|---|---|
| 直立墓碑 ×2 | 可见高约 58 | **64～80** |
| 十字碑 | 70 | **80～96** |
| 打开的墓穴 | 长度比主角还短 | 坑的长边**不短于主角身高**（约 100～120），墓穴要显得能躺下一个人 |
| 盖板 | 跟着墓穴放大 | 与墓穴的坑口大小相配 |
| 矮墙 / 墙柱 | 46 / 56 | 墙 **52～64**，柱比墙高一截 |
| 铁栏 | 58 | **64～80** |

底座贴花现在只有几小撮苔藓，物件像“放在地上”。请做厚一点：**下沉的泥土压痕、翻起的湿泥、一圈被压倒的枯草、少量碎石**，范围略大于物件的接触面，让物件像是“长在泥里很多年”。

整体也要**更旧**：北极星图里的墓碑偏暗、苔藓多、边缘破。现在的物件偏浅灰、偏新，在深色地面上很跳。
