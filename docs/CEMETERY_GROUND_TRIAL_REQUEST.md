## 4. 试样要画什么

一块 **480×270** 的地面（正好是屏幕的四分之一），**只画平的东西**：

- **湿泥**占大部分：深灰褐，局部棕橙色的泥块；
- **稀疏的枯草**：贴在地上、被压倒的枯草（站起来的草丛是另外的贴花，不画进地面）；
- **一两片小积水**：冷灰蓝，暗暗地反光，**不能是饱和的青蓝色**（那是游戏里“语言”专用的颜色）；
- **一段残缺的石板小路**斜穿过画面：石板下沉、缺失、被泥盖住、被草侵蚀，有一两块错位。石板要有磨损的边、苔藓、裂缝，精致程度向墓碑看齐，但它是平躺的；
- **不要画**：墓碑、墙、树、高的草丛、骨头、任何有高度的东西，以及地面投影。

视角和墓碑一致：**斜着往下看的 3/4 俯视**，平躺的东西上下方向被压扁（看 `grave_slab_01.png`、`open_grave_01.png` 平躺的样子）。光从左上来。

### 精致程度：上限和下限都要守

- **下限**：不能是平涂，不能是迷彩斑块。每一小块颜色都说得出是什么：泥块、湿泥的反光、车辙或水流冲出的沟、碎石子、压倒的草茎、石板的磨损边……
- **上限**：地面是背景，**要比墓碑和主角“安静”**。不能铺满高频的杂点，不然墓碑和主角会被淹没。明暗对比也要比物件小一档。
- 数字参考（`python3 scripts/tools/pixel_check.py <文件>`）：颜色 30～60；相邻像素换色比例大约 55～75%（现在的临时地面 47%，太平；墓碑 83～88%，地面不需要这么高）。**以眼睛看为准**，不要为数字加杂点。

### 颜色

- 方向按美术圣经：深灰褐、冷、湿，棕橙色泥块和冷灰蓝积水交错。
- **要和物件的底座贴花接得上**：可以从 `art/cemetery_v3/props/*_base.png` 里取泥的颜色。物件放上去，底座边缘不应该出现一圈明显的色差。
- 现在墓碑偏暖黄、地面偏冷蓝，试样要找到让两者像在同一块地上的颜色。
- 游戏里会给整个画面乘一层色调（RGB 约 0.80 / 0.84 / 0.92，略压暗、偏冷）。**素材本身按正常颜色画**，检查图里请给出“乘了色调”和“没乘色调”两种。

## 5. 像素规格

| 项目 | 要求 |
|---|---|
| 尺寸 | 480×270，完全不透明 |
| 像素 | 真像素：无半透明、无抗锯齿、无平滑渐变；不能整体缩小、不能非整数缩放、不能平滑 / 取平均 |
| 饱和青蓝 | 0 个像素 |
| 不要 | glitch、像素错位、发光、地面投影 |
