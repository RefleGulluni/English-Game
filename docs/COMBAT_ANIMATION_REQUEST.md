## 3. 主角施法 Cast（左 / 右，6～8 帧，约 0.6～0.8 秒）

- **所有词共用这一条**。区别各个词的是程序画的几何，不是动作，所以动作要“中性”：不是挥拳、不是劈砍，是**说出 / 调用一个词**。
- 推荐的动作（你们可以更好）：身体微微前倾 → **空着的那只手**（提灯的是右手）朝敌人的方向抬起、手掌张开或指向前方 → 停住一拍（出手帧）→ 放下、回到站姿。书在腰前，书上的青蓝小印记跟着身体动，**形状不变、不闪、不变亮**（发光由程序加）。
- 朝右施法时，抬起的左手在身体靠近镜头的这一侧还是另一侧，按你们的透视判断，QA 里说明。朝左时同理，**不要直接镜像**。
- **提灯**仍然挂在手上、比身体慢半拍摆动（HERO §7）。
- 出手帧大约在第 3～4 帧（约 250～350 ms）。整个动作克制、稳定，**“理解”不是“爆发”**：不要甩披风、不要大幅后仰。

## 4. 主角受击 Hit（左 / 右，3～4 帧）

- 被骷髅的骨刃划中：上身往**远离敌人**的方向一缩（1～3 px），头和肩稍晚一帧，提灯被带着晃一下，然后回到站姿。
- 脚不动。不要倒地、不要闪白。

## 5. 骷髅攻击 BONE CUT（左 / 右，8～10 帧）

- 它的物理攻击叫 **BONE CUT（骨刃割）**：用**断掉的前臂骨的尖茬**横着划过去。没有武器，就是它自己的骨头（你们的设计 QA 写了“没有额外武器”，请保持）。
- 三段：
  1. **蓄力**（3～4 帧，慢）：骨盆先往后坐，肩膀晚一帧跟上，挥击的手臂被**往后扯开**，像有根线把它拉到身后；可以有一块骨头偏出 1～2 px 再被拉回。
  2. **挥击**（1～2 帧，快）：手臂一下子划到身前，这一帧是**命中帧**。不要拖影，靠前后两帧的位置差表现快。
  3. **收回**（3～4 帧）：一顿一顿地被拉回站姿，裹尸布下摆晚一拍落下。
- **画布 160×96，脚底锚点 (80, 96)**：朝右攻击时手臂最远可以伸到 x≈150（身体前方约 70 px），朝左时伸到 x≈10。身体本身仍在画布中间，脚不动。
- 游戏里双方隔约 120 px。程序会在蓄力时让骷髅**整体往前挪一步（40 px）**、收回时退回，所以手臂伸到身前约 60～70 px 就能碰到主角。QA 里写明命中帧时刃尖离脚底中心多少像素。
- 动作的感觉照骷髅 §1：**被牵着的骨头**，不是一个人在挥刀。

## 6. 骷髅抖落骨灰 GRAVE DUST（左 / 右，6 帧）

- 它的非攻击行动（GRAVE DUST、ERODE、TOXIC DUST）都是“身上落下尘土”。所以做一条共用的：骨架整体**抖一下**（像被扯了一下），肩上、肋骨间、布褶里落下几簇**灰尘像素**，落到脚边消失。
- 灰尘用骨头和布里已有的暗色；不要做成烟雾特效，就是几小簇往下掉的像素。
- 第 1 帧 = 站姿，最后一帧回到站姿。
