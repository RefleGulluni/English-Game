## 2. 它是谁

> **Body ended. Presence remains.**
> 身体已经不在了，但“存在感”还没散。

- **不是“半透明的人形怪”**，不要通用的白床单鬼、发光幽灵、骷髅脸鬼魂。
- 设定里的样子：人形、偏薄；和雾融在一起；**脸不完整**；送葬时的衣物和身体分不清边界；**身体不连续**（有的地方断开、缺一截）。它像“一个没能正确离开这个世界的人”。
- 它的玩法（游戏已经写好规则）：
  - **FADED（隐去）**：偶数回合进入，直接攻击只有一半效果，玩家会觉得“打不着它”；
  - 玩家对它用 **OBSERVE（观察）** → **REVEALED（显形）** 一回合，轮廓稳定下来，能真正打到它；
  - 它还会**用假的意图骗玩家**（FALSE INTENT）。
  - 这条敌人教给玩家的是：**“看懂了它，才终于能碰到它。”**

所以每个方向**必须同时画两种状态**，这是这一轮最重要的部分：

1. **REVEALED（显形）**：完整、实心的像素形象。被看懂之后的样子，轮廓清楚、填充完整。
2. **FADED（隐去）**：**同一张画布、同一个位置**，同一个形象“没完全落到像素网格上”。Art Bible §11 的做法：
   - 用**抖动（dithering）**和**稀疏的像素**表现，即一部分像素直接去掉（变成全透明），**不是**整体调成半透明；
   - **局部先消失**：哪里先散、哪里还留着，由你们设计（例如脸和下半身先散，送葬的面纱 / 衣领还在）；
   - 轮廓断断续续，和背景混在一起；
   - **不用模糊**。

   FADED 版的每个不透明像素，都要和 REVEALED 版**同一位置的像素颜色相同**（只删像素、不改颜色）。这样程序可以在两者之间做“慢慢显形”的过渡。

## 3. 像素规格

| 项目 | 规格 |
|---|---|
| 画布 | **96×128**，透明背景。“站立点”锚点在 (48, 127)，也就是它在地上的位置（Y 排序用）；它可以不着地，下摆散开在锚点附近 |
| 身高 | Art Bible §21.4：Ghost “可更高、更轻”。从头顶到下摆 **100～120 px**（主角 96 px） |
| 视角 | 与主角一致的 3/4 俯视世界；**正对镜头**（同 `hero_B1_front_straight.png`） |
| 光源 | 左上 |
| 像素 | 真像素：**Alpha 只有 0 和 255**，无抗锯齿、无渐变。按制作手册 §5：单独生成大方块像素风 → 找真实像素格、一格还原一个像素 → 逐块整理。不能整体缩小、不能非整数缩放 |
| 精致程度 | **REVEALED 版**向主角看齐：颜色 30～50、相邻像素换色比例不低于 80%（主角 44 色 / 88%），用 `python3 scripts/tools/pixel_check.py` 检查；每一小块颜色都要说得出是什么 |
| 颜色 | 偏冷、低饱和的灰白 / 灰蓝 / 灰绿都可以，但要在雾中墓径的冷灰地面（平均色约 (60, 63, 62)）上**站得出来**，不能和地面混成一片 |
| 描边 | **不加**整圈描边 |
| 阴影 | **不画地面投影** |
| 禁用颜色 | **饱和的青蓝色是语言层专用**（单词、Lexicon、True Words），Ghost 身上一点都不能有，也不要发光、光晕 |
| 禁用效果 | 不要 glitch、撕裂、像素错位（Fracture 永远不破坏像素网格） |

可读性：按游戏里的 2 倍大小、放在雾中墓径地面上看，要求：
- 和主角、骷髅「余裹者」的**剪影明显不同**；
- REVEALED 一眼能看清是一个“人形的存在”；
- FADED 看得出“还在那里，但抓不住”，**不能淡到找不到它**：玩家必须知道敌人在哪，只是觉得打不实。

## 4. 方向

出 **3 个方向（A / B / C）**，彼此要差得开（剪影、哪里先消失、身上留下的“生前的东西”都不同）。下面只是举例，可以不用：
- 头上蒙着送葬面纱的人，面纱比身体更“实”；
- 裹在长斗篷里、看不见脚、下摆化成雾的守墓人；
- 只剩上半身清楚、双手抱着某样东西（花、灯、遗物）的人。
