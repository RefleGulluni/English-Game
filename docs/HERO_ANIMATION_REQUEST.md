# 主角 B1 动画需求 · 第一批：待机 + 行走

> **发给：Codex 角色设计组**
> 日期：2026-10-24。撰写：Claude（程序）。验收：Claude 在 Godot 墓地场景实机检查，用户拍板。

## 0. 这一批做什么

只做 **待机（Idle）** 和 **行走（Walk）**，四个方向各一套，共 8 条动画。
翻书（打开 Lexicon）、受击、战斗动作放到后面几批，**这一批不要做**。

**分两步交付：**

1. **试做：只做“右侧行走”一条**（往画面右边走）。交付后我在游戏里看，确认步幅、速度、提灯摆动都对了再继续。
2. **其余 7 条**：右侧待机、左侧待机/行走、正面待机/行走、背面待机/行走。

先做右侧，是因为侧面最能看出走路好不好看，而且右侧图刚返工通过，正好检验它能不能“动起来”。

## 1. 起点：四张标准站姿（不能改）

| 方向 | 标准图 | 说明 |
|---|---|---|
| 正面 | `art/character_design/hero_B1_front.png` | 原版 B1，3/4 朝画面右下。往下走时用 |
| 背面 | `art/character_design/hero_B1_back.png` | 往上走时用 |
| 左侧 | `art/character_design/hero_B1_left.png` | 面朝画面左 |
| 右侧 | `art/character_design/hero_B1_right.png` | 面朝画面右，2026-10-23 返工版，已通过 |

- **每条待机动画的第 1 帧，必须和对应标准图逐像素完全相同。**
- 行走的每一帧都要能看出是同一个人：头身比、外套长度、配件位置都和标准图一致。
- 高清参考 `reference/hero_B1_concept_hires.png` 用来检查有没有走样，不要把它当成像素素材来缩小。
- 左右以**角色本人**为准：**右手提灯，左髋挎包，包带从右肩斜跨到左髋，书在腰前略偏右**。
- **左右两侧不能互相镜像**（灯和包在不同的手、不同的髋上）。

## 2. 技术规格（所有帧通用）

- 每帧画布 **96×96 px**，透明背景。
- **脚底锚点 (48, 96)**：站立和行走时，着地的那只脚落在最底一行（y = 95）。身体的水平中心保持在 x ≈ 48 附近，**不要在画布里往前走**，位移由游戏来做。
- 每一帧都是**真像素**：
  - 没有半透明像素（alpha 只能是 0 或 255）；
  - 没有抗锯齿和模糊；
  - 没有动态模糊、拖影帧（smear）。
- **调色板**：只使用四张标准图里已经出现过的颜色，不要新增颜色。
- **不画地面阴影，不画灯光光晕**。接触阴影和灯光由 Godot 处理。
- 书上的**青蓝小印记**跟着身体移动，形状保持不变，**不闪烁、不变亮**（发光效果以后由程序做）。

## 3. 待机 Idle（每个方向 4 帧，循环）

- 节奏：每帧 **250 ms**，一个循环 1 秒。游戏里可以调速度，帧数请保持 4 帧。
- 动作要非常小，像人在安静地呼吸：
  - 胸口、肩膀随呼吸起伏 **1 px**；
  - 提灯在手下轻轻晃 **1 px**，比身体慢半拍；
  - 外套下摆可以有 1 px 的轻微变化，也可以不动。
- 头和脚不动。**第 1 帧 = 标准图。**
- 不要眨眼，不要转头，不要做“看书”这类小动作（以后可能单独做“闲置小动作”）。

## 4. 行走 Walk（每个方向 8 帧，循环）

- 节奏：每帧 **100 ms**，一个循环 0.8 秒，左右各迈一步。
- 游戏里的行走速度约 **70 px/秒**，所以每一步大约前进 **28 px**。步幅请按这个画，否则会出现“脚在地上打滑”。
- 帧顺序（以侧面为例）：
  1. 右脚在前着地（接触）
  2. 身体压低（承重）
  3. 左腿从后往前经过（经过）
  4. 身体最高点（抬起）
  5. 左脚在前着地（接触）
  6. 身体压低
  7. 右腿经过
  8. 身体最高点
- 身体上下起伏 **1～2 px**，不要更多。
- **提灯**：像钟摆一样跟着步子前后摆，比身体慢半拍，最大摆幅约 2～3 px。灯要始终能看清剪影，**不能压到外套上**（参考右侧返工版留出的空隙）。
- **空手**自然前后摆动，和脚的方向相反。
- **外套下摆**：跟着腿的动作轻微摆动，是行走好看的关键，请多花心思。
- **挎包**：随步子轻微上下 1 px。
- **正面 / 背面**：脚步主要表现为上下交替和左右轻微晃动。正面原图是 3/4 朝右下，行走时保持这个角度，不要改成正对镜头。

## 6. 我会怎样验收

我会把动画接进墓地场景（`graveyard_room`），在游戏里用 2 倍大小实际走一走，重点看：

1. 走路时脚有没有在地面上打滑（步幅和速度对不对得上）；
2. 换方向时，人会不会忽大忽小、忽高忽低（锚点是否一致）；
3. 提灯在暗色地面上还能不能看清；
4. 走到墓碑、枯树后面变成半透明时，看起来是否正常；
5. 和墓地背景放在一起，像不像同一个世界里的东西。

旧主角的 `art/cemetery_pixel_v1/player_anim/` 已经作废，**不要参考**。
