# 发给：Codex 美术组 — 墓园“风格统一样品”

日期：2026-10-25。需求方：Claude（程序），用户拍板。
接上一轮 `docs/CEMETERY_ENV_DESIGN_REQUEST.md` 的交付（`art/cemetery_v3/design/`）。

## 1. 为什么先做这个

上一轮三个方向的构图都不错，QA 也写得很诚实。但用户在游戏里看到：**主角和背景不像同一个游戏**。主角是干净的像素画，背景“有点写实”，像一张照片被缩小了。因此用户决定：**先保证风格统一，再选方向。**

Claude 把主角放在 A 方向的墓穴旁，放大 3 倍对比，差别在三处：

1. **边缘**：主角每块形体边缘都有深色像素收边（外套、裤子、靴子轮廓利落）；背景的墓碑、墙、墓穴边缘是软的，从亮到暗慢慢过渡，没有收边。
2. **颜色成块还是成颗粒**：主角外套是几块明确的棕色（亮 / 中 / 暗）；背景泥地几乎每个像素都在变色，满地细碎颗粒。
3. **制作方法**：上一轮是 1672×941 生成后缩到 960×540（1.74 倍，不是整数），AI 图里原本的像素块对不上新网格，碎成了颗粒。

Claude 试过用程序自动整理（合并碎像素 + 减色）：地面变成块了，但墓穴和石砖变得斑驳难看。**滤镜解决不了，需要按主角的标准认真整理。**

参照：用户觉得上一批样板地面 `art/cemetery_pixel_v1/plates/ground_plate_960x540.png` 和主角是搭的。它的颜色更成块、颗粒少得多，可以作为地面的参考方向。

## 2. 这一轮做什么

**只做一小块样品，不做整张图。**

从 `art/cemetery_v3/design/bg_skeleton_room_A.png` 截取右侧这一块：**x 600～960、y 180～440（360×260 原生像素）**。里面有打开的墓穴和它旁边的石板、右上的残墙、下方的矮墙与铁栏、墓碑和十字碑、一片湿泥地与积水。

按主角的标准重新整理，出 **两个强度**：

- **V1 · 收敛版**：保留现在的构图和材质感，只做到“和主角统一”所需的最少修改。
- **V2 · 风格化版**：更大胆，色块更大、细节更少、更像经典像素游戏。

两版都要满足：

| 项目 | 要求 |
|---|---|
| 网格 | 原生 1:1 整数网格。**不要再用非整数倍缩小**：要么在原生尺寸上逐块整理 / 重画，要么先找到生成图真正的像素格再按整数倍采样 |
| 物件边缘 | 墓碑、墙、铁栏、墓穴、石板都要有**深色收边**，用该材质自己最暗的那档颜色，不是统一的黑线，也不是整圈描边（主角就是这样） |
| 明暗层次 | 每种材质 3～4 档明暗 + 最多 1 档高光，光从左上来；颜色成块，不要满地单个杂色像素 |
| 地面 | 大块组织：泥、积水、枯草各自成片；细碎纹理大幅减少；可参考样板地面 |
| 主角对比 | 主角棕色外套站在棕色泥地上不够醒目。战斗区附近的泥地请略**偏冷、偏灰**一点，或者多一点低饱和的灰蓝积水，让主角跳出来（不能用加描边解决） |
| 颜色 | 世界里不能有饱和青蓝色。**更正上一轮的需求**：主角书上的青蓝小印记是 Lexicon 的符号，本来就该是青蓝，合成时请保持原样，不要改成灰色 |
| 其他 | 不画地面投影；不要 glitch |
