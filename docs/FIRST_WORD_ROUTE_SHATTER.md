# 第一条学词路线：SHATTER（设计草稿）

日期：2026-10-29。状态：**已定（D-078，用户：“就用 SHATTER”“开始搭灰盒”）**，按第 6 节搭灰盒。
依据：知识库 Learning System Current Reference §3～§4（四个阶段、三种证据、一次只推进一个大阶段）、D-075（SHATTER 等词在墓园各局里学会）、词条 `data/words/entries/shatter.json`（`appears`、`stage_lines`、`challenge` 已写好）、0.8 的 `learning_schedule.evidence()`（识别 → RECOGNIZED、语境 → UNDERSTOOD、产出 → USABLE，已有代码）。

## 1. 一句话

玩家在新墓园里**一路碰到“碎”这件事四次**：先看见、再认出、再借来用一次、最后自己选对。每次只前进一格。第四次以后，SHATTER 正式进牌，后半局打骷髅明显轻松，这就是“理解即力量”。

## 2. 四步

| 阶段 | 在哪里 | 玩家做了什么 | 玩家看到什么 | 书里 |
|---|---|---|---|---|
| **见过** ENCOUNTERED | 第 1 个房间：翅膀碎掉的天使雕像 | 什么都不用做，走近就行 | 雕像上方浮出残缺的 `sha___` 和一道裂纹，走开就淡掉 | 多了一页：残缺字形，没有释义 |
| **认得** RECOGNIZED | 事件房「碎翼天使」 | 走近按 E，读一句话，从 3 个意思里选一个 | 场景内文字框：*The wing did not fall. It was shattered.* 选项是三个短英文释义（打成碎片 / 慢慢磨损 / 散落一地） | 铅笔字 + 释义 “break into many pieces” |
| **理解** UNDERSTOOD | 下一场骷髅战 | 骨堆快要重组时，手里**多出一张铅笔画的 SHATTER**（只借这一次），打在骨堆上 | 骨堆被打得粉碎，这一次重组被打断；记录写 “SHATTER — understood” | 铅笔描成墨水；写上机制：结构伤害 8，打骨堆最有效 |
| **能用** USABLE | 事件房「裂开的石板」 | 一块封住坟的裂石板，选项是**玩家会的词**（STRIKE / BIND / OBSERVE …… / SHATTER），选 SHATTER | 石板碎开，下面的东西被放出来（奖励）；随后书自己翻开，SHATTER 亮起青蓝 | 青蓝微光；SHATTER 加进牌（1 张） |

为什么是这四件事：

- **见过不考人**（知识库：自然出现约占 60%，只记“见过”）。
- **认得**用一道很轻的题：这是事件房（玩家心里已经准备好“读一读”的地方），符合“明确的题只放在 Investigation 这类地方”。干扰项用的是同一场景里的近义词：scatter（骨头散了一地）、erode（磨损），正好是词条里写的易混词。
- **理解**用行动证明，不答题（知识库最重要的“用行动证明理解”那一层）。借一张临时牌，牌组已经支持（`deck_state.reset` 的 `temporary_cards`）。
- **能用**是“在新的语境里自己选对”：选项不是三个意思，而是玩家自己的词。这也是以后所有事件房的格式。

## 3. 一局里的节奏

一次只推进一个大阶段，所以 SHATTER 至少要碰到 4 次（第一次是免费的）。按 6 层一局：

- 第 1 层：见过 + 第一场骷髅战（只有 5 个词，有点吃力，**故意的**：让玩家先体会“骨堆一直重组好烦”）；
- 第 2 层：认得（事件房）；
- 第 3 层：理解（骷髅战，借来的 SHATTER）；
- 第 4 层：能用（事件房）；
- 第 5～6 层：带着 SHATTER 打，感觉到变强。

## 4. 做错了怎么办

- **不扣分、不倒退**：选错只是“这一次没前进”，场景给一句提示（*Not scattered. Look at the edges.*），这个词留到后面的房间再遇到。
- 理解那一步不出那张借来的牌（或出了没用），下一场骷髅战再借一次。
- 已经学会的阶段**永远不丢**（D-075 “The world forgets. You do not.”）。第二局开始时，SHATTER 从上次停下的阶段继续；已经 USABLE 的话，这些房间换成下一个词的路线（DEFLECT、RESTORE……）。

## 5. 每一步“在书里亮一下”

学词要被看见：每前进一格，屏幕角落出现一行发光小字（如 `SHATTER — recognized`），同时书在主角手里轻轻一闪；按 Tab 打开书，能看到这一页从残字 → 铅笔 → 墨水 → 青蓝。**能用**那一步书自己翻开到这一页（只这一次，体现“学会了一个能力”）。
