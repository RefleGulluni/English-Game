## 0. 地面试样的结果，和这次为什么先做远景

你们的地面试样已在游戏里看过（谢谢如实写出拼接失败）：

- **好的**：泥地够安静，石板有厚度和磨损，和物件底座接得上，比原来的冷蓝迷彩地面好很多；
- **要改的**：太暖、太单一，满屏棕色，不像又冷又湿的墓园，主角的棕色风衣容易融进去；
- **拼接**：失败。一张生成图只能还原约 250×140，整张地面怎么做（整张地面板，还是“安静泥地底子 + 一块块地面贴花”）还**等用户拍板**，所以地面先停一停。

与此同时，用户按自己画的草图搭了第一个正式房间：**墓园入口**（灰盒截图 `docs/reference/cemetery_entry_greybox.png`）。房间最上方露出天空、天际线和礼拜堂的轮廓，用户特别喜欢这部分“神秘、诡异的氛围感”。这一次就做它，外加画面下角的前景枯枝。

## 1. 远景条 `entry_backdrop_01`

放在房间的最上方（房间坐标 y = 0 起），在所有墓碑、铁栏的后面。

| 项目 | 要求 |
|---|---|
| 尺寸 | **960×100**，完全不透明 |
| 上段（约 y 0～45） | 灰白的阴天，冷，带一点点云层的横向纹理；不要太阳、不要发光 |
| 中段（约 y 30～70） | 起伏的**暗色天际线**：远处的山坡、枯树林、矮墙的剪影，高低错落，不要规则的波浪 |
| 礼拜堂 | **在 x 440～520 一带**，哥特式小礼拜堂的**轮廓**：一座尖塔高出天际线，衬在天空上；只要剪影和极少的细节（一两扇暗窗），不画清楚 |
| 下段（约 y 70～100） | 远处的地面，颜色和天际线相近；Claude 会在上面盖一层流动的薄雾，所以这里画得简单就行 |
| 颜色 | 冷灰、灰蓝，比地面和物件暗、对比低（远的东西更淡、更灰）；**没有饱和青蓝**（语言层专用） |
| 像素 | 和整个世界同一像素大小：一格 = 一个原生像素，不能放大、缩小 |

**注意尺寸问题**：一张生成图只能还原约 250 格宽，960 宽要拼。建议拆开做：

1. **礼拜堂**：单独生成一件（单件物件你们已经很熟），还原后放到位置上；
2. **天际线**：剪影颜色少、细节少，可以分 3～4 段生成，接缝在整理时用同样的剪影颜色补齐；
3. **天空**：几条横向的灰色色带 + 少量云纹，可以直接整理，不需要生成。

做法、接缝怎么处理，请在 QA 里写清楚。如果拼不好，**停下来说明**。

## 2. 前景枯枝 `fg_branches_left_01`、`fg_branches_right_01`

镜头刚进入房间时，画面最下面左右两个角伸进来的枯枝，盖在所有东西上面，让人感觉“刚从树林里钻出来”。

| 项目 | 要求 |
|---|---|
| 尺寸 | 每张约 220×150，透明背景；左边那张贴着画面左下角，右边那张贴着右下角 |
| 样子 | 几乎全黑的枯枝剪影，枝杈分叉，末端细；可以有一两片残叶；左右两张形状不同（**不能镜像**） |
| 细节 | 很少：只在枝条上沿留一点点暗灰的受光边（光从左上来） |
| 不要挡路 | 中间（画面 x 380～580）留空，不要伸到路上 |
| 像素 | 真像素，alpha 只有 0 / 255，无抗锯齿 |

## 5. 验收结果与补充（2026-10-25，第一次交付后）

已换进入口灰盒看过（Claude 也把自己的薄雾压低到天际线以下，免得盖住远景）：

- **天际线：通过。** 枯树林、坡地、矮断墙的剪影很有气氛，接缝看不出来。10 色、少细节正合适，远景就该这么安静。
- **前景枯枝：通过。** 左边高出 25 像素没关系，保留。
- **礼拜堂：要放大。** 现在可见 36×53，在游戏里太小，像天际线上的一个小尖。用户喜欢的是灰盒占位那种“黑沉沉压在天空上”的感觉，礼拜堂是整个墓园的终点地标，要一眼就看到。

请只重做礼拜堂，存为 `entry_backdrop_02.png`（**不要覆盖 01**）：

| 项目 | 要求 |
|---|---|
| 大小 | 可见约 **70～90 宽、85～100 高**：尖塔顶几乎碰到画面最上沿（y 2～6），殿身下部被天际线的坡地挡住 |
| 位置 | 尖塔仍对准 x≈480 |
| 样子 | 哥特式小礼拜堂，**一座高尖塔 + 两侧较低的殿身或扶壁**，轮廓要有分量；只有剪影和极少细节（两三扇暗窗、塔尖的十字架）；**比天际线更暗一档**，在天空上最醒目 |
| 不要 | 发光的窗、清楚的石材细节、青蓝色 |

天空、天际线、薄雾用的远地面都沿用 01，只把礼拜堂换掉。交付 `qc/backdrop_02_on_greybox_2x.png` 和 QA 补充一段即可，完成后停下。
