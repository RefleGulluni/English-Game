# 主角与 Lexicon 设计 — 决定记录

日期：2026-10-23。素材在 `art/character_design/`，由 Codex 角色设计组生成，Claude 验收，用户拍板。
世界观部分已写入 World Bible 第 6、8.1（含“书封符号”）、12.1、36 节。

## 1. 一句话结论

主角是 **B1：一个记录世界的男性旅人**（长棕外套、翻领、浅色衬衫、左髋挎包、右手提灯、腰前挂着一本书）。
**那本书就是 Lexicon。** 定稿素材是原版 `hero_B1.png`，**一个像素都不改**。四方向设定图已完成，下一步是动画。

## 3. 怎么走到这里

1. 旧主角（兜帽斗篷 + 长剑）太像通用暗黑剑士、太中世纪，也缺少 Lexicon，被否决。
2. A/B/C/D 四个方向中，用户和 Claude 都选了 **B（记录世界的旅人）**；B1～B3 中选 **B1**。
3. 用户提出：**Lexicon 就是主角身上的那本书**。打开的 Lexicon 界面就是翻开的书；锚点共鸣的对象是这本书；书页的四种状态（空白 → 铅笔 → 墨水 → 青蓝发光）对应四个学习阶段。
   设计边界：**学会的单词不会因为死亡或没到锚点而丢失**。锚定只是“为什么理解能留下来”的解释。
4. 书封符号定为 Claude 的方案 A：
   - 三个节点 = Concept / Language / Reality
   - **底边中间断开** = Fracture
   - 外圈 = Lexicon
   - 中心点 = 主角
5. 角色身上的小符号试了四版（`hero_B1_book.png`、`_v2`、`_v3`、`_v4`），全部**不用**：
   - v1 带外圈，读成了发光的圆徽章或笑脸。
   - v2 画成了“∧”。
   - v3 像素合格，但书是规整矩形加黑边框，像贴上去的牌子。
   - v4 合格，但用户最终觉得原版 B1 就很好。
6. **最终决定：直接用原版 B1，书上原本的青蓝小印记就是符号的“缩写”。** 大书封保持完整符号，大小两版不要求一样。
7. 四方向设定图交付后用户接受。

## 5. 经验（以后改角色时）

- **修改像素角色时只改最少的像素**，不要单独画一块新东西贴上去，否则会显得突兀。
- 一张标准图不要重新生成，其他方向都照着它画。四方向里的正面直接复制原文件。
- 角色左右的道具不一样，**侧面不能镜像**。
- 验收看游戏里实际的大小（在墓地地面上 2 倍显示）；8 倍放大只用来查技术问题。
- 给美术组讲微小图案时，**直接给像素规格图**，比用文字描述有效得多。
- `reference/` 里大量 `*_claude.png`、`*_mock.png`、`*_spec.png` 是符号试验过程的示意图，已经没有用，留着只作为记录。
