## 1. 上一轮结果

三个方向的质量都很高（42～48 色、换色 89～94%），摆进游戏试走房间后，用户选定 **B「余裹者 / Shroud-kept」**，评价“非常好”。
理由：缩回游戏大小后，A、C 接近标准骷髅，绳和钉要凑近才看得清；B 的斜披破布一眼可认，骨堆也最好认。

- **A、C 不删**，保留在原位，以后做“精英骷髅”时作变化参考（例如在 B 上加 C 的三枚棺钉和锯齿缝线）。
- 小提醒（这一轮不用改）：骨头是全画面最亮的颜色。等真地面和雾做好后可能整体压暗一点，到时另行通知。

## 3. 身份标记在每个方向的位置（最重要）

左右以**骷髅本人**为准（正面图的画面左 = 骷髅的右）。B 的身份标记：

- 裹尸布从**右肩**斜跨到**左胫**，带破洞和斜下摆；
- **两枚铁钉在右肩**，把布钉在肩骨上；
- 布上的**黑色 X 形缝线**；
- **额部斜包布**、**腰绳**；
- 空手。

这些东西在背面、左侧、右侧分别露出哪一部分，**必须前后一致**：
- **背面**：布从背后看，应该在画面**右侧**（骷髅的右肩在背面图的画面右边），能看到布搭过肩膀垂到背后；肩钉从背后可能只看到钉尖或看不到，请在 QA 里说明你的处理。
- **右侧**（面朝画面右，朝镜头的是骷髅的**右半边**）：肩钉、布从右肩垂下的部分最明显；
- **左侧**（面朝画面左，朝镜头的是骷髅的**左半边**）：布主要在身体另一侧，可能只露出搭过胸前的部分、下摆（布斜到左胫，这一侧的小腿附近会看到）和腰绳。
- **左右两侧不能互相镜像**：布和钉都在同一边，镜像就错了。

如果你们觉得某个方向的布“读不出来”，可以在**不改正面**的前提下，在 QA 里提出调整方案，先别自己改。

## 4. 规格

| 项目 | 要求 |
|---|---|
| 画布 | 每张 96×96，透明；脚底锚点 (48, 96)，最低不透明像素 y=95 |
| 身高 | 和正面一致（96 px） |
| 视角 | 和主角四方向一致的 3/4 俯视：侧面能看到一点头顶和肩膀上沿；**正面 / 背面的“脚锁地面”不要照搬侧面的画法**（俯视角下前后被压缩，主角这里返工过一轮） |
| 颜色 | **只用正面图和骨堆里已有的颜色**，不新增颜色 |
| 精致程度 | 和正面同一档：颜色 30～50、换色比例不低于 80%；每一小块颜色说得出是什么 |
| 像素 | 真像素；按制作手册生成 → 逐格还原 → 整理；不能缩放、镜像、旋转 |
| 不要 | 发光、青蓝、地面投影、描边 |

站姿要方便以后做动画：四肢之间留出透明空隙，布和骨头的前后关系清楚。
