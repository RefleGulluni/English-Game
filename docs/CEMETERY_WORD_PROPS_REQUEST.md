# 发给：Codex 角色设计组 — 墓园“词汇物件”8 件

日期：2026-10-29。需求方：Claude（程序），用户拍板（用户：“角色组先做词汇物件吧”）。
先读：`docs/PIXEL_ASSET_PIPELINE.md`、`docs/CEMETERY_ENTRY_PROPS_REQUEST.md`（上一批的写法和规则，本批照旧）。

## 1. 背景：为什么要这一批

谢谢你们上一批入口物件（哀悼天使、枯树、铁门、路灯……）。用户在游戏里走完说：**“我以后就想要这种质量的素材”**（D-060）。**这一批的质量标准就是那一批。**

游戏的核心是“理解即力量”：玩家在世界里遇到英语单词，走近一样东西时，它上方会浮出单词（这一层由程序画，不归你们）。我们刚定下第一批 42 个单词（`docs/VOCABULARY_FIRST_BATCH.md`），其中一些词在墓园里**还没有对应的东西**：渡鸦、钟、被苔藓盖住名字的墓碑、封死的墓穴、老井、新埋的坟。这一批就是把这些词“放进世界”。

每件后面写了它对应的单词和世界里的小故事，帮助你们理解它要传达什么。**物件上不能有任何可读的字母**（可读英文只属于语言层）。

## 2. 要做的物件

尺寸以主角可见高 96 px 为参照，写的是**立体部分的可见高度**。每件照常：立体部分 + `_base` 底座贴花，同一原点（底边中心），画布底部透明留白不裁；manifest 照常登记。

| 文件名 | 是什么 | 大小参考 | 要点（对应的词） |
|---|---|---|---|
| `raven_ground_01` | 站在地上的渡鸦 | 身长约 26～32，站高约 18～24 | **raven**。大，粗壮的喙，楔形尾。羽毛深近黑但**不是纯黑**：要有一点冷灰紫的高光，放在深色泥地上也读得出轮廓。侧身 3/4，头微微转向镜头。`_base` 很小（几粒踩乱的土）或留空 |
| `tombstone_raven_01` | 一块墓碑 + 站在碑顶上的渡鸦 | 墓碑同 `tombstone_upright_01` 的大小；渡鸦同上 | **raven**，“The ravens do not fear the dead.” 渡鸦和墓碑**画成一件**（Y 排序按墓碑的脚，渡鸦单独摆上去会排错）。墓碑用已通过墓碑家族的石头和颜色，碑面只有看不清的刻痕 |
| `tombstone_mossy_01` | 名字被苔藓盖住一半的墓碑 | 高约 50～64 | **moss / conceal / epitaph**，“Moss does not conceal a name out of malice.” 立着的旧墓碑，**苔藓从碑的下半部和一侧爬上来，盖住刻字的一半**：露出来的那一半只是看不清的刻痕。苔藓是低饱和的灰绿，一团一团、有厚度，不是平涂的绿色。`_base` 里苔藓延伸到地面 |
| `grave_bell_01` | 坟头上的小铃 | 高约 40～52 | **bell / bury / linger**。旧时怕把活人误埋，在坟头立一根细铁杆，顶上挂一只小铜铃，铃绳垂下来**钻进土里**。铃是暗沉的旧铜（可以有一点低饱和的铜绿），杆子锈。`_base` 是一小块新翻过又压实的土，绳子入土的地方要看得出来 |
| `bell_frame_01` | 墓园的钟架 | 高约 110～140，宽约 60～80 | **bell / echo / silence**，“The bell rings once for each new grave. Nobody has heard it in years.” 两根粗木柱 + 一根横梁（可以有一个小小的木顶），横梁下挂一口比 `grave_bell_01` 大得多的铜钟，钟绳垂下来、末端磨破。木头和 `signpost_01`、木十字架同一种旧木 |
| `crypt_sealed_01` | 被封死的小墓室门面 | 宽约 120～150，高约 110～140 | **seal / bind**，“Some doors in this place were sealed from the inside.” 一座小墓室的正面（山墙、两根短柱、一扇石门或铁门），**门被封住**：铁条横钉、锁链缠了几圈挂着大锁，门缝用铅或灰浆抹死。石头和墓碑、高门柱同一个石匠。只画正面这一面，进深靠下面的台阶和 `_base` 表现。门楣上的铭文只画成看不清的刻痕 |
| `old_well_01` | 老井 | 井圈宽约 60～72；带木架总高约 90～110 | **toxic**，“Nothing grows near the old well. The water remembers what was poured into it.” 圆形石砌井圈，一个歪斜的木架、绳子和吊着的旧木桶。往井里看是**深暗的水面**，水面有一点浑浊的油光（低饱和，**不能是亮绿色、不能发光**）。`_base`：井的周围一圈**寸草不生**的灰褐死土，和外面的地面有清楚的边界——这是“有毒”唯一的提示 |
| `fresh_grave_mound_01` | 刚埋好的坟 + 插着的铁锹 | 土堆长约 56～70；铁锹露出高约 34～44 | **bury**，“The caretaker buries the dead at dawn, so that no one has to watch.” 一个隆起的新土堆，土比地面**湿、深、松**，表面有铁锹拍过的痕迹；一把旧铁锹斜插在土堆一头。没有墓碑（还没来得及立）。土堆整体画进 `_base`，立体部分只有铁锹 |

### 规则（和上一批一样）

- 精致程度和主角同一档：颜色约 30～50、相邻像素换色比例不低于 80%（小件以眼睛为准），用 `python3 scripts/tools/pixel_check.py` 量；
- 真像素：生成大方块像素风 → 找到真实像素格 → 一格还原一个像素 → 逐块整理（制作手册的流程）；
- 不画地面投影、不描边、**没有饱和青蓝**、不镜像、不旋转、不发光；光从左上来；
- 石头、木头、铁和已通过的物件同一套材质与颜色：石头看墓碑家族和 `gate_pillar_tall_01`，木头看 `signpost_01` 和木十字架，铁看 `iron_fence_01`；
- `_base` 的颜色要融进正式地面：深灰褐泥地约 (70,70,60)、碎石泥路约 (93,88,73)、枯草苔藓地约 (67,71,55)，见 `docs/reference/ground_paint_room_grass_01.png`；
- 尺寸以“放得下、看着对”为准：如果写的上限让东西挤得难看，**可以超出，在 QA 里说明**，不要为了凑数删像素（喷泉删行出过“横切一刀”的问题）。
