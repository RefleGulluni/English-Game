## 0. 为什么交给你们

主角 B1 是目前游戏里唯一一个**真正的像素画**：在 96 像素的画布上，对着定稿图一块一块整理出来的。

墓园背景已经让美术组做了两轮（`art/cemetery_v3/design/`、`art/cemetery_v3/style_test/`），用户的结论是：**都不像像素画，更像“被像素化的写实画”**。原因是做法不对：先用 AI 生成一张细腻的大图再缩小，底子就是写实的，后面怎么修都很难变成像素画。

因此用户决定（知识库 Decision Log D-026）：

- 整张场景图**只用来定构图**，不再是最终素材；
- **每个物件单独按像素画来做**，标准和主角一样，由你们负责；
- 美术组负责地面与整体构图。

## 2. 什么叫“像素画”（这一批的验收标准）

- 在**原生尺寸**上设计，每个像素都是有意放的；缩回 1 倍依然能一眼认出是什么。
- 形状**简化、概括**：几个像素暗示一块石头的裂口，不画写实纹理。
- 每种材质 **3～4 档明暗 + 最多 1 档高光**，颜色成块；光从左上来。
- 形体有**深色收边**（用该材质自己最暗的那档，和主角一样），不是整圈黑线描边。
- 颜色**从北极星图里的地面、石头、苔藓、树上取**，不要取图里人物的颜色；不要整体偏棕，也不要整体偏蓝。苔藓的橄榄黄绿是这个世界的点缀色。
- 世界里**不能有饱和青蓝色**（语言层专用）。不画地面投影，不要 glitch。
- **禁止**：先画大图再缩小；非整数倍缩放；半透明、抗锯齿、渐变。

## 3. 第一批物件（先少做，做对）

都是 A 残墙院落里的东西，尺寸以主角 96 像素为参照：

| 物件 | 大约尺寸（高） | 说明 |
|---|---|---|
| 直立墓碑 ×2 款 | 48～64 | 一块完整的、一块缺角的 |
| 十字碑 | 56～72 | |
| 打开的墓穴 + 盖板 | 占地约 96×64 | 坑内要有深度；盖板斜放在旁边 |
| 矮墙段 + 墙柱 | 高 40～56 | 一段完整、一段残断；以后能拼接 |
| 铁栏段 | 高 48～64 | 可以接在矮墙上，也可以单独立着 |

每个物件都要按 NOTES.md 的做法：**立体部分**（参与遮挡）+ **底座贴花**（贴地的泥土、压痕、枯草），两张图原点相同（底边中心）。
