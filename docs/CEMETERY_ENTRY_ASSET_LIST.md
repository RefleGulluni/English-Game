# 墓园入口（Cemetery Entry）素材清单

建立：2026-10-25（Claude）。决定来源：Decision Log D-036、D-038、D-039、D-040。
灰盒：`scenes/prototypes/cemetery_entry/cemetery_entry_greybox.tscn`（WASD 走路，H 开关占位说明）。
灰盒截图：`docs/reference/cemetery_entry_greybox.png`（上：走到大门前；下：刚进来）。

## 1. 这个房间长什么样

用户画的框架，Claude 补的细节：

- **两屏高**（960×1080），镜头只上下跟着主角。第一屏看不到大门，往上走时大门和墓园才慢慢露出来。
- **下半部分（门外）**：一条弯弯的泥路从屏幕下边缘伸上来；路边有孤零零的穷人坟、枯树、积水、倒下的路灯、歪倒的路牌；中段有墓园外圈塌掉的旧乱石墙（墓园以前更大）；最下面两个角伸进来前景枯枝。
- **中间**：横贯画面的铁栏 + 柱子；两根**高大的门柱**夹着大门，一扇铁门半开，一扇倒在门内地上。
- **上半部分（门里）**：正对大门是一座**干涸、残破的喷泉**，中间立着残缺的哀悼天使像；喷泉左右两条小路通到画面顶部的**两个出口**（去第 1 层，出口即选路）；两侧隔着铁栏是一片片墓碑。
- **最上方**：灰白的天空、起伏的暗色天际线，**礼拜堂的轮廓**衬在天空上，下面压一层薄雾。

- 薄雾层（会流动）、主角提灯的光、墓灯的光；
- 出口符号、镜头跟随（已在灰盒里）；
- 正式房间场景：把占位换成新素材的积木，配碰撞。

## 4. 顺序

1. 美术组：远景条 + 前景枝（现在）；
2. 角色组：骷髅四方向（进行中）→ 入口物件；入口物件里**先做门柱**（它要和铁栏拼，最容易出问题）；
3. 用户拍板地面做法 → 美术组做入口地面；
4. Claude 把新素材换进灰盒，用户走一遍验收。
