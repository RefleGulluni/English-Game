## 0. 背景

- 游戏现在能完整走通第一条“学词路线”：玩家在墓园里一路碰到 **SHATTER（打碎）** 这个词四次，最后学会它（`docs/FIRST_WORD_ROUTE_SHATTER.md`）。
- 第二次碰到它是在第 2 个房间：一座干涸的喷泉，中间立着哀悼天使。玩家走近按 E，读到：*The angel keeps one wing. … It was **shattered**.*，然后从三个意思里选对“打碎”。
- **问题**：房间里用的是你们做的入口喷泉 `art/cemetery_v3/props/fountain_dry_01.png`（已通过，入口素材的质量标准），天使的翅膀是**完整的**。文字说“碎了”，画面里却没碎，玩家对不上。
- 这一次要一个**翅膀被打碎的版本**，让玩家亲眼看到“shattered”是什么样子。

**以 `fountain_dry_01.png` 为底子改，不重新生成整件。** 只改这几处：

1. **翅膀碎了**：看得见的那只翅膀（画面右侧）在**大约一半处断掉**。断口是**参差的、新鲜的碎茬**：断面颜色比风化的表面浅一点（里面的石头没被风吹黑），能看出是“一下子碎成很多块”，不是“慢慢风化掉”。剩下的半截翅膀保持原来的羽毛画法。
2. **碎片落在池子里**：天使脚下、池底的泥上散着 **5～9 块大小不一的石头碎片**（大的约 6～10 px，小的 1～3 px），有一两块大的还能看出羽毛的纹路。碎片要像**刚掉下来不久**：比池底的泥和落叶干净、浅一些，但不能比天使的脸和骨头亮。
3. **其余一律不动**：池子、池沿缺口、天使的身体和脸、底座、苔藓、颜色，**逐像素保持原样**。新画的部分颜色从原图里取（可以加两三个“新鲜断面”的浅石色）。

**不要的**：翅膀整只消失（要能看出“这里原来有翅膀”）；碎片飞在空中；裂纹发光；饱和青蓝（那是语言专用）；镜像、旋转。

## 3. 2026-10-30 验收：第一版做工很好，但在游戏里看不出“碎了”，请返修

谢谢：原图一个像素都没乱动、断口和碎片都用原图的颜色和羽毛、QA 写得清清楚楚，这些做法全部保留。

**问题**：按游戏里的实际大小看（Claude 已把第一版换进第 2 个房间截图），翅膀只像“下半截短了一点”，池底 7 块碎片几乎看不见。用户：“现在这一版就感觉没碎啊”。我们的原则是**提示要让没被告知的玩家走过去就能发现**，所以“碎”要做得更狠、更显眼。这是需求写得太保守的错（“大约一半处断掉”“碎片 5～9 块，大的 6～10 px”）。

### 新的要求（取代第 1 节第 1、2 条）

1. **翅膀从靠近肩膀的地方断掉**：只留下贴着肩背的一小截茬（大约原翅膀高度的 1/4～1/3），断口参差、断面颜色比风化表面浅（保留第一版的做法）。远远一看，天使的轮廓就要明显“少了一只翅膀”。
2. **断下来的一大块翅膀掉在池里最显眼的地方**：一整块能认出羽毛的大碎块（约 **18～26 px** 长），**斜靠在天使底座的正面或侧前方**，或者躺在池底靠前、不被池沿挡住的位置。它就是那只翅膀的大半截，用原翅膀的像素整数移过去（不旋转、不镜像；角度不对就用原图像素重新拼，宁可在 QA 里写明）。
3. **再加 3～5 块中等碎片**（约 5～10 px），散在池底前半部分，**其中 1～2 块落在池沿上**（池沿是亮的，碎片放上去才看得见）；可以保留第一版的几块小碎屑。
4. 其余要求不变：其余像素不动、颜色从原图取、不加光、不要饱和青蓝、不旋转不镜像。

**自查**：把成品缩到 1 倍（游戏里的实际大小），和原版并排，**不看说明**，一眼就能指出“右边这座天使的翅膀断了，断的那块在这里”。做不到就停下写进 QA。

交付同第 2 节，**覆盖** `fountain_broken_wing_01.png`（第一版已在 git 里，不用另做备份），QC 图换新，另加一张 `qc/fountain_broken_wing_01_1x_compare.png`（原版和返修版的 1 倍并排）。完成后停下，等用户验收。

## 4. 2026-10-30 第二版验收：看得出“断了”，但还不是“碎了”，请再改一轮

谢谢：第二版在游戏里一眼能看出少了一只翅膀，肩部断茬和“用原翅膀像素拼碎块”的做法都对，继续保留。

**用户的意见（原话）**：“碎了就是碎的，翅膀不是一个整体，是很多石头的碎块在地上”；“它现在那种状态是**断了**，而不是**碎了**，那个断口感觉不像是碎掉的，像是断掉了。”

这正好是这个词要教的东西：**break / snap（断）= 一下子分成两截，断口比较整齐，掉下来的是一整块；shatter（碎）= 一下子炸成很多块，断口是放射状的裂纹和缺口，碎块四散。** 玩家在这个房间要学的是 shatter，所以画面必须是“碎”，不是“断”。

### 新的要求（取代第 3 节第 1～3 条；第 3 节第 4 条和自查照旧）

1. **肩上剩下的茬要“碎过”，不是一刀切开**：
   - 断口是**参差的尖角**：几根长短不一的尖茬，不是一条平滑的线；
   - 茬上有 2～3 处**崩掉的小缺口**，露出深一点的断面；
   - 从断口往肩背方向有 2～3 条**细裂纹**（1 px 深色线，短、分叉），表示整块石头被震裂了；
   - 可以有 1～2 小块“快掉还没掉”的碎片，和茬之间隔一道 1 px 的暗缝。
2. **地上不要“一整块翅膀”，要“很多块”**：
   - 拿掉第二版那一大块（27×26）。断下来的翅膀**碎成很多块**：
     - 2 块**中块**（约 10～14 px），还能看出一点羽毛刻槽，让玩家联想到“这是翅膀的碎片”；
     - 6～10 块**小块**（约 3～8 px），棱角分明的不规则多边形，**不要圆的**；
     - 一些 1～2 px 的**石屑**。
   - 每块都是**亮的新鲜断面 + 暗一点的侧面**，看得出是刚碎的石头。
   - **分布像“砸下来溅开”**：在翅膀正下方（天使右后侧）最密，往外越来越稀；一部分落在底座台阶上，1～3 块落在池沿上，可以有一两小块溅到池子外面的地上（画进 `_base` 或本体都可以，在 QA 里写明）。
   - 碎块加起来的面积**大约等于少掉的那部分翅膀**，看起来像“翅膀都在这里了，只是碎了”。
   - 碎块继续用原翅膀的像素切出来、整数移动，不旋转、不镜像。
3. **自查**：
   - 1 倍并排，不看说明：**“这只翅膀碎成了很多块”**，而不是“翅膀断下来一块”；
   - 再和第二版并排：能说出“第二版是断，第三版是碎”的区别。
   - 做不到就停下写进 QA。

交付同第 2 节，**覆盖** `fountain_broken_wing_01.png`（第二版已在 git 里，不用另做备份），QC 图换新，1 倍对比图改成**原版 / 第二版 / 第三版**三张并排（`qc/fountain_broken_wing_01_1x_compare.png`）。完成后停下，等用户验收。
