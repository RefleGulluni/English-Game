# 地面刷路方法（正式做法，D-055 / D-056）

2026-10-27 用户拍板：“咱们以后就用这个方法来设计小路吧！” 这份文档说明这套方法是什么、为什么这样做、怎么用、怎么加新的地面种类。所有地区、所有地图的地面都照这个做。

## 1. 一句话

**用户在 Godot 里用画笔刷“哪里是路”；程序保证路的边缘怎么拼都对得上；美术只画路面长什么样。**

| 谁 | 负责什么 | 东西在哪 |
|---|---|---|
| 用户 | 路往哪走、在哪分叉、哪里是草地（亲手刷） | 房间场景里的 TileMapLayer |
| Claude 的程序 | 每块 32×32 瓦片里路的**形状**：不规则的边、湿泥边、零星碎石；保证任意两块都接得上 | `scripts/tools/build_ground_path_masks.py` |
| 美术组 | 路面的**纹理**：一张 224×128 的无缝图，做法和大块泥地底子一样 | `art/cemetery_v3/ground/transitions/path_texture_01.png` |
| 着色器 | 把美术的纹理按位置“贴”进程序画的形状里 | `scripts/world/v3/ground_path.gdshader` |

## 2. 地面是几层叠起来的

从下往上：

1. **底子层**（`Ground/Base`）：两块 224×128 的大块无缝泥地（`ground/base/ground_base_01.png`、`_02.png`），随机铺满整个房间；
2. **路层**（`Ground/Path`）：用户刷的碎石泥路。瓦片里泥地的部分是**透明**的，露出下面的底子；
3. （以后）**草地层**、**苔藓地层**……每种地面一层，做法完全一样；
4. **贴花**：积水、落叶、碎石子等 20 件，平贴在地上，打破重复（以后做成可拖的积木）；
5. **物件积木**：墓碑、墙、门柱，站在地面上。

## 3. 为什么这样做（踩过的坑）

| 试过的做法 | 结果 | 学到的 |
|---|---|---|
| 一整张生成图当地面 | 质感好，但一张只能还原约 250×140，拼不起来 | 生成图大小有天花板 |
| 32×32 小块泥地瓦片 | 像绒布、看得出格子 | 32 px 放不下泥地纹理 |
| 224×128 大块无缝底子 | **通过** | 大块能放下大小两层变化 |
| 让美术按 4×4 排法画 16 块路的边角 | 失败：边界偏了最多 14 px | 生成图守不住精确几何；而且刷路时**任何两块角码相同的瓦片都会挨在一起**，同一种边必须处处一模一样，只有程序做得到 |
| **程序画形状 + 美术画纹理 + 用户刷** | **通过** | 精确的交给程序，质感交给美术，创意交给人 |

## 4. 原理（给以后维护的人）

### 4.1 为什么是 16 种瓦片
地面被分成 32×32 的格子。每个格子的四个角，各自是“路”或“不是路”，2⁴ = 16 种组合；全不是路的那种是空的，所以要 15 块。Godot 的 TileSet 地形用 **Match Corners（按角匹配）** 模式：每块瓦片标好“哪几个角是路”，用户刷的时候 Godot 自动挑角码对得上的那一块。原理和“双网格（Dual Grid）”相同，同一套瓦片两种做法都能用。

### 4.2 为什么任意两块都接得上
`build_ground_path_masks.py` 给每块瓦片算一个“路的程度” f：

```
f = 四个角的双线性插值
  + 一份每 32 px 重复一次的噪声（所有瓦片共用）
  + 一份每块自己的噪声 × 一个在格子边上为 0 的权重
f ≥ 0.5 是路；刚过 0.5 的一小圈是湿泥边；刚不到 0.5 的地方零星撒碎石
```

一条边上的 f 只取决于**这条边两头的两个角** + **共用噪声**，所以只要两块瓦片在这条边两头的角一样，边缘就严丝合缝，不管它们来自哪里。每块自己的噪声在格子中间才起作用，让路不会每 32 px 一模一样。

### 4.3 为什么路面不重复
瓦片里“路里面”的像素是**纯白**，只是一个记号。着色器画到纯白时，按这个像素在地图上的**世界坐标**，去 224×128 的路面纹理里取颜色（纹理四边首尾相接）。所以路面是一整张连续的图，不会出现 32 px 的格子；换一张纹理，所有已刷好的路同时换样子。湿泥边、碎石的颜色是瓦片里直接画的，照原样显示。

## 5. 用户怎么刷（中文步骤）

1. 在 Godot 编辑器里打开房间场景（试验房间：`scenes/prototypes/ground_paint/ground_paint_room.tscn`）；
2. 左边场景树点 **Ground → Path**（以后草地就点 Ground → Grass）；
3. 底部 TileMap 面板点 **Terrains**，选 **碎石泥路**；
4. 在画面上按住左键拖动刷路，右键擦掉；
5. Cmd+S 保存，F6 运行，WASD 走上去看。

**重要**：用户刷好的场景是用户的作品。`build_ground_paint_room.gd` 只在场景**不存在时**才生成；改形状或纹理不需要重刷，已刷的路会自动更新。

## 6. 加一种新地面（例如草地）的步骤

1. **美术组**：画一张 224×128 无缝纹理（`ground/transitions/<名字>_texture_01.png`），流程同大块底子：生成 → 逐格还原 → 平移半张修十字 → QA；需求写法见 `docs/CEMETERY_GROUND_TRANSITION_REQUEST.md` §5、§7；
2. **Claude**：用 `build_ground_path_masks.py` 生成这种地面的形状（换一个噪声种子和边缘风格：路是湿泥边 + 碎石，草地是参差的草尖），输出到 `transitions/masks/`；
3. **Claude**：在 `build_ground_paint_room.gd` 里给它建一个 TileSet（Match Corners，一个地形）和一层 TileMapLayer（同一个着色器，换纹理），加进房间场景，**不覆盖用户已刷的层**；
4. 截图给用户看，用户亲手刷，通过后在 Decision Log 记一条。

每个地区（墓园、车站……）各有自己的一套底子和纹理，形状程序和着色器通用。
