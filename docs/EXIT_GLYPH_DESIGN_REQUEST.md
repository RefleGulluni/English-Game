## 0. 背景

**出口即选路**（Decision Log D-023，知识库 `03_WORLD_AND_LEVELS/English_Game_Scene_Structure_and_Transitions.md` §4）：每个房间有 2～3 个出口，玩家走向哪个出口，就是选了哪条路，没有单独的地图界面。每个出口上方浮着一个**发光小符号**，告诉玩家后面是什么类型的房间。这个符号属于**语言层**（同像素密度、唯一青蓝、精确几何、平稳）。

现在用的是 Claude 最早画的占位（`docs/reference/exit_glyphs_8x.png`，从左到右：战斗、事件、休息、精英、换区域），太粗糙，要换掉。

**你们刚做的 9 个词类符号已通过，用户很满意**（`art/ui/word_sigil_v3/glyphs/`，检查板 `art/ui/word_sigil_v3/qc/family_glyphs_labeled_8x.png`）。出口符号请用**同一套几何语法**：1 px 线、整数坐标、水平 / 竖直 / 45°、端部基准、规则断口、不画象形图标。但它们表达的是“**地方**”，不是“词的类别”，两套要能一眼分开（见 §2）。

## 2. 规格

- **15×15 px**（比词类符号的 11×11 大一圈：出口符号浮在房间边上，要从远处认出来）。图形用中间 13×13，外圈 1 px 透明。
- **白色画在透明底上**，alpha 只有 0 / 255；程序染青蓝、加发光和缓慢的上下浮动。
- 1 px 线；不要光晕、渐变、纹理、第二种颜色。
- **和词类符号分开**：建议给出口符号一个共同的“地方”特征（例如所有出口符号都有一条底边基准，像门槛 / 地平线；或者都朝上收成一个开口），让玩家一眼知道“这是路，不是词”。具体由你们设计，QA 里说明用了什么共同特征。
- 危险程度要有层次：战斗 < 精英 < 最终。休息、遗物要显得“安全 / 有回报”，但不能用暖色（只有一种青蓝），靠形状表达。
