## 0. 为什么换做法

你的地面试样证明了两件事：

- **质感可以做到**：泥地安静，石板有厚度和磨损，和物件底座接得上；
- **整张拼不起来**：一张生成图只能还原约 250×140，左右续画拼接有接缝、石板路断开。墓园入口是 960×1080，要拼约 30 块，不现实。

所以用户决定：**以后所有地图的地面都用“瓦片 + 地面贴花”**：

- **底子瓦片**：32×32 的泥地小方块，几种变体随机铺满，用户在 Godot 里用画笔刷；
- **过渡瓦片**：泥地和石板路之间的边缘，用户刷一条路，Godot 自动选对边角；
- **地面贴花**：积水、湿泥斑、压倒的枯草、落叶、松动的石板，单独的透明小图，像积木一样摆上去，打破重复。

小块正好在“一张生成图约 250 格宽”的能力范围内，这是这条路最大的好处。

**必须避开的老问题**：项目 2026-10-22 试过一套旧瓦片（`art/cemetery_pixel_v1/terrain/`，只能看“不要什么”），用户的评价是**“平、空、机械”**：看得出方格、花纹重复、没有墓园的湿冷质感。这次的试样会和你的整张试样 `ground_trial_01.png` **并排比较**，如果仍然“平、空、机械”，这条路就要重新讨论。

## 1. 颜色：要冷、要湿

你的整张试样颜色**太暖、太单一**（满屏棕色），主角的棕色风衣会融进地面。这次：

- 整体是**冷的、湿的深灰褐**：泥带一点灰绿或灰蓝的冷调，局部才有少量暖褐色的泥块；
- **主角站上去要跳出来**：主角的风衣是暖棕色，地面要比它冷、比它暗；
- 比物件安静：相邻像素换色比例约 **55～75%**（物件是 80% 以上），颜色总数整套约 20～35 色；
- 已通过物件的**底座贴花**（`art/cemetery_v3/props/*_base.png`）要能自然放在新地面上，如果冷暖接不上，在 QA 里说明，**不要自己改底座**；
- 积水是冷灰蓝、暗暗反光，**不能有饱和青蓝**（语言层专用）；
- 感觉参照北极星图 `art/pixel_test/source/graveyard_P_reference.png`（明暗、冷暖、湿度），不是颜色仓库。

## 2. 要做的东西

### 2.1 泥地底子：8 块变体

- 每块 **32×32**，完全不透明；
- **任意两块左右、上下相邻都无缝**（不只是和自己无缝）。做法建议：每块边缘一圈只用底色和很小的纹理，明显的东西（石子、泥块、草茎）放在块的中间、不压边；
- 8 块里：4 块很安静（主要铺满用），4 块带一点小特征（小石子、一点草茎、一小块深色泥），特征**不能一眼认出**，否则重复会很明显；
- 随机铺满一整屏（960×540）后**看不出格子、看不出重复**，这是最重要的验收标准。

### 2.2 泥地 ↔ 石板路过渡：16 块一套

- 每块 32×32；用“**四角匹配**”：每块的四个角各自是“泥”或“石板路”，2⁴ = 16 种组合，正好 16 块（含全泥、全路）；
- 排成 4×4 一张 `ground_path_corners_01.png`（128×128），再附 `ground_path_corners_01.json` 写明每块四个角各是什么（例：`{"x":0,"y":0,"tl":"mud","tr":"mud","bl":"mud","br":"path"}`）；
- **全路的那块另外多做 2 块变体**（`ground_path_full_01.png`，96×32，三块横排），否则长路会重复；
- 石板路的样子参照你整张试样里的石板：有厚度、磨损、缝里有泥和草，边缘是**残缺不齐**的（老路被泥吞掉了一部分），不要整齐的直边；
- 过渡区不要只是一条硬线：石板边缘有碎石、泥漫上石板。

### 2.3 地面贴花：6～8 件

透明背景，alpha 只有 0 / 255，**只画平的东西**（站起来的草丛、石头不算，那是物件）：

| 文件 | 内容 | 大小参考 |
|---|---|---|
| `decal_puddle_01`、`_02` | 积水，一小一中 | 约 30×14、60×24 |
| `decal_wet_mud_01` | 一片更深更湿的泥 | 约 50×24 |
| `decal_dead_grass_01`、`_02` | 贴地、被压倒的枯草片 | 约 30～50 宽 |
| `decal_leaves_01` | 一小撮湿落叶 | 约 24×12 |
| `decal_loose_slab_01` | 一块松动、半陷进泥里的石板（同石板路的石头） | 约 30×18 |
| `decal_cracked_slab_01`（可选） | 裂开的石板 | 约 30×18 |

贴花的**边缘要和泥地底子的颜色接得上**：放在任何一块底子上都不能有一圈“贴纸感”的硬边。

## 3. 怎么做

照制作手册：生成大方块像素画 → 找真实像素格、一格还原一个像素 → 逐块整理。

- 底子：建议生成一张约 250×140 的“安静冷湿泥地”，还原后从里面挑 32×32 的块，再手修四边做成互相无缝；
- 石板路：单独生成一段有残缺边缘的石板路，还原后切成 16 块，手修角落接缝；
- 贴花：单件生成，和物件一样。

如果某一步做不通（例如 8 块变体无论怎么修都看得出重复），**停下来写进 QA**，不要自己换成别的做法。
