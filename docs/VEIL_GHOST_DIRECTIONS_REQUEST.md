## 1. 一个改变：FADED 以后由程序做

第一轮的 FADED（固定 4×4 有序抖动删像素）在游戏里看起来像纱窗 / LED 屏，偏机械。这不是做错了，是静态图做不到“慢慢散开又聚拢、能打断、能倒放”。所以：

- **以后只交 REVEALED（显形）图**，FADED 由 Claude 的着色器实时做；
- 你们画的**“先散顺序”密度图非常有用**（`qc/veil_ghost_sources/A_retention_density.png`：脸、手、腹部、下摆先散，面纱两侧最稳），着色器就拿它当遮罩。所以**每个方向都要交一张同画布的密度图**（见 §3）。

## 2. 这一轮做什么

以 `veil_ghost_A.png`（正面，96×128，锚点 (48,127)）为准，补齐 **背面、左、右** 三个方向的站姿（**左右不镜像**，各自画）。规格全部沿用第一轮需求 `docs/VEIL_GHOST_DESIGN_REQUEST.md` §3（96×128、锚点 (48,127)、Alpha 只有 0 / 255、30～50 色、换色比例 ≥ 80%、无描边、无投影、无饱和青蓝、无发光）。四方向的做法照骷髅：`art/character_design/enemies/skeleton/skeleton_B_back.png` / `_left.png` / `_right.png` 和它当时的 QA。

另外两点：

1. **整体略压暗一点**（四个方向一起，包括正面）：A 的最亮处现在几乎和骷髅骨头一样亮，而骨头已经是全画面最亮的东西。目标：最亮的面纱高光比骷髅最亮的骨头暗一档，仍然在雾中墓径冷灰地面上站得出来。正面改亮度时**只改颜色，不改像素位置和形状**（`veil_ghost_A.png` 原文件先备份到 `qc/backups/round1/`）。
2. 侧面和背面要保留 A 的身份：面纱顶的尖、两侧垂下的面纱、合拢的手（侧面能看到一点）、三个错落的布尾、布上的小破洞。背面看不到脸，面纱从头顶一直垂到背后。
