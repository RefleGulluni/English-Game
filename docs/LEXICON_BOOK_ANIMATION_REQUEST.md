## 0. 背景

**Lexicon** 是主角随身带的一本实体书，玩家学会的每个英语单词都记在里面，永远不会丢。按 Tab 打开：世界压暗，一本放大的书出现在屏幕正中。书里是一张“星图”：每个词是一颗星，意思相近的词连成星座（知识库 `02_SYSTEMS/02_Learning/English_Game_Lexicon_Interface_Design.md`）。

现在的灰盒只是把**摊开的书**淡入、往上浮。用户希望有真正的**翻开 / 合上**动画。分镜见 `docs/reference/lexicon_open_storyboard.png`（6 格；第 3 格的半开封面是 Claude 把图压扁做的示意，**正式的要你们画**，像素画不能靠压扁或旋转）。

整个过程（翻开约 0.7 秒，合上约 0.4 秒，可以随时打断倒回）：

| 阶段 | 发生什么 | 谁做 |
|---|---|---|
| ① 升起 | 合着的书从下方升到屏幕中间，背景压暗 | 程序 |
| ② 唤醒 | 封面上暗刻的符印亮起青蓝光 | 程序（用你们给的遮罩） |
| ③ 翻封面 | 封面以书脊为轴从右往左翻过去 | **你们画 5 帧** |
| ④ 连线 | 星座的点和连线一条一条亮起 | 程序 |
| ⑤ 可用 | 单词浮现 | 程序 |
| 合上 | 倒着播一遍 | 程序 + 同样 5 帧倒放 |

另外以后书里有很多层（星图 → 星座 → 单词页），需要**翻页**，一起做。

## 2. 要画的东西

### 2.1 干净的书（最重要，先做）

语言层（青蓝）必须由程序画：每个玩家学会的词不一样，星座也就不一样，而且连线要一条一条亮起，所以**书本身不能带青蓝色**。

| 文件 | 内容 | 画布 |
|---|---|---|
| `lexicon_closed_clean.png` | 合着的书。封面上的符印（三角形三节点、底边中间断开、外圈、中心点）画成**暗刻在皮面上的凹痕**：用皮面已有的暗色和亮色表现凹下去的边，**一个青蓝像素都没有** | 128×128 |
| `lexicon_open_clean.png` | 摊开的书。书页只有纸、污渍、旧痕；**没有星点、没有连线、没有青蓝**（铅笔画的小方框、小点这类“世界里的痕迹”可以保留少量，但不要像星图） | 256×128 |
| `lexicon_sigil_mask.png` | 符印的**白色遮罩**：和 `lexicon_closed_clean.png` 同样 128×128，符印的位置画白色、其余透明。程序用它在凹痕上发光 | 128×128 |

### 2.2 封面翻开（5 帧）

`lexicon_cover_open.png`：5 帧横排，**每帧 256×128**（和摊开的书一样大）。

- **书脊在每一帧都是同一个位置**（画布正中 x≈128），不动。合着时书停在画布**右半边**（也就是摊开后右页的位置），封面绕书脊往左翻。
- 第 1 帧：合着的书（= `lexicon_closed_clean.png` 放在右半边，逐像素相同）；
- 第 2 帧：封面右边缘掀起，封面变窄，露出一点下面的书页；
- 第 3 帧：封面几乎竖直，只看到一条窄窄的封面边；两页纸露出来；
- 第 4 帧：封面翻过书脊，落向左边，看到的是封面的**内侧**（就是左页的背面 / 衬页），还没完全放平；
- 第 5 帧：摊开（= `lexicon_open_clean.png`，逐像素相同）。
- 透视按俯视的“桌上翻书”来画，你们觉得 5 帧不够可以 6 帧，QA 里说明。

### 2.3 翻页（4 帧）

`lexicon_page_turn.png`：4 帧横排，每帧 256×128。

- 第 1 帧 = `lexicon_open_clean.png`；右页掀起 → 竖立 → 落到左边；最后一帧回到 `lexicon_open_clean.png`（翻过来的那页也是空白纸，所以看起来和第 1 帧一样即可）。
- 只翻**一页**，纸要薄、要轻，和厚皮封面的翻动感觉不一样。

## 3. 规格

| 项目 | 要求 |
|---|---|
| 颜色 | 只用设计图里书本身已有的颜色（皮面、纸、金属扣、书签带）。**不新增颜色，不要青蓝** |
| 像素 | alpha 只有 0 / 255，无抗锯齿、无模糊、无拖影、无运动模糊；不缩放、不镜像、不旋转 |
| 不要 | 发光、光晕、阴影投在桌面 / 地面、描边、速度线 |
| 大小 | 游戏里书的 1 个像素 = 3 个原生像素（约占屏幕宽度 80%），所以细节按 3 倍看效果 |
| 时长 | 每帧时长写进 `art/character_design/anim/timing.json`（只追加）：封面翻开建议共约 0.25 秒；翻页共约 0.2 秒。程序合上时会倒放并加快 |

## 5. 我会怎样验收

Claude 把它们接进游戏（Tab 打开），用户实际开合几次，看：
1. 合着的书升起、符印亮起、封面翻开、连线亮起这一串连不连贯，书在翻的时候会不会跳；
2. 封面翻动有没有“厚皮封面”的分量，翻页有没有“薄纸”的轻；
3. 干净的书配上程序画的青蓝符印和星座，像不像原来的设计图；
4. 合上时倒放加快会不会看起来乱。
