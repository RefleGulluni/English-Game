## 0. 背景

**Lexicon** 是主角随身带的一本实体书，玩家学会的每个英语单词都记在里面，永远不会丢。按 Tab 打开：世界压暗，一本放大的书出现在屏幕正中。书里是一张“星图”：每个词是一颗星，意思相近的词连成星座（知识库 `02_SYSTEMS/02_Learning/English_Game_Lexicon_Interface_Design.md`）。

现在游戏里（v3 墓园按 Tab）已经能看到整个过程，程序部分都做好了，**只有书本身的动作是灰盒色块**，等你们的帧。截图 `docs/reference/lexicon_open_ingame_v2.png`；用户的翻法示意 `docs/reference/lexicon_open_upright.png`（侧面看：书脊在下、左右封面同时往两边倒）。

整个过程（**用户在游戏里调好的速度**：翻开约 2.3 秒，合上约 1.8 秒，可以随时打断倒回）。**书始终在屏幕正中**：合着时是封面居中；立起来以后，书脊就固定在屏幕中线上，一像素都不动：

| 阶段 | 发生什么 | 谁做 |
|---|---|---|
| ① 升起 | 合着的书升到屏幕正中，**封面正对玩家**，背景压暗 | 程序 |
| ② 唤醒 | 封面上暗刻的符印亮起青蓝光 | 程序（用你们给的遮罩） |
| ③ 立起来 | 书往后一仰，**立在书脊上**：封面从“正对玩家”转到朝向左右，从上往下看只剩一条窄窄的书页边 | **你们画 3 帧** |
| ④ 透光 | 两张封面之间的缝里透出一道青蓝光 | 程序 |
| ⑤ 两边倒下 | **左右两张封面同时往两边倒下**，书页跟着散开，最后摊平 | **你们画 5～6 帧** |
| ⑥ 星座 | 星座的点和连线从书脊开始亮起，词浮现 | 程序 |
| 合上 | 整个倒着播，最后封面又正对玩家、符印熄灭 | 程序 + 同样的帧倒放 |

另外以后书里有很多层（星图 → 星座 → 单词页），需要**翻页**，一起做。

## 2. 要画的东西

### 2.1 干净的书（最重要，先做）

语言层（青蓝）必须由程序画：每个玩家学会的词不一样，星座也就不一样，而且连线要一条一条亮起，所以**书本身不能带青蓝色**。

| 文件 | 内容 | 画布 |
|---|---|---|
| `lexicon_closed_clean.png` | 合着的书。封面上的符印（三角形三节点、底边中间断开、外圈、中心点）画成**暗刻在皮面上的凹痕**：用皮面已有的暗色和亮色表现凹下去的边，**一个青蓝像素都没有** | 128×128 |
| `lexicon_open_clean.png` | 摊开的书。书页只有纸、污渍、旧痕；**没有星点、没有连线、没有青蓝**（铅笔画的小方框、小点这类“世界里的痕迹”可以保留少量，但不要像星图） | 256×128 |
| `lexicon_sigil_mask.png` | 符印的**白色遮罩**：和 `lexicon_closed_clean.png` 同样 128×128，符印的位置画白色、其余透明。程序用它在凹痕上发光 | 128×128 |

### 2.2 立起来（3 帧）+ 两边封面倒下（5～6 帧）

两条都是横排，**每帧 256×128**（和摊开的书一样大）。**画布中线是 x = 128**：合着时**封面居中**在中线上（真实书脊在封面左边）；立起来的过程中书脊移到中线；**从立起来的最后一帧起，书脊固定在 x = 128**，倒下的每一帧都不动。（2026-10-29 角色组指出原写法“每帧书脊都在 x = 128”和“合书居中”冲突，以本段为准。）

`lexicon_tip_up.png`，3 帧：
- 第 1 帧 = `lexicon_closed_clean.png` 放在画布正中（封面正对玩家，逐像素相同）；
- 第 2 帧：书往后仰到一半，封面变窄（绕左边的书脊转），书脊往画布中线移；
- 第 3 帧：**书立在书脊上**，从上往下看只看到一条窄窄的书页上边（两侧是封面的边），宽约 10～16 px，高和书一样，正好在中线上。

`lexicon_covers_fall.png`，5～6 帧：
- 第 1 帧 = 上面第 3 帧（立着的书）；
- 中间：**左右两张封面同时往外倒**，对称；书页像扇子一样跟在封面后面散开，比封面慢一点；
- 最后一帧 = `lexicon_open_clean.png`（摊平，逐像素相同）。
- 透视按“俯视桌上的书”来画；左右两边要对称但不要镜像复制（书页的旧痕不一样），拿不准的写进 QA。

### 2.3 翻页（4 帧）

`lexicon_page_turn.png`：4 帧横排，每帧 256×128。

- 第 1 帧 = `lexicon_open_clean.png`；右页掀起 → 竖立 → 落到左边；最后一帧回到 `lexicon_open_clean.png`（翻过来的那页也是空白纸，所以看起来和第 1 帧一样即可）。
- 只翻**一页**，纸要薄、要轻，和厚皮封面的翻动感觉不一样。

## 3. 规格

| 项目 | 要求 |
|---|---|
| 颜色 | 只用设计图里书本身已有的颜色（皮面、纸、金属扣、书签带）。**不新增颜色，不要青蓝** |
| 像素 | alpha 只有 0 / 255，无抗锯齿、无模糊、无拖影、无运动模糊；不缩放、不镜像、不旋转 |
| 不要 | 发光、光晕、阴影投在桌面 / 地面、描边、速度线 |
| 大小 | 游戏里书的 1 个像素 = 3 个原生像素（约占屏幕宽度 80%），所以细节按 3 倍看效果 |
| 时长 | 每帧时长写进 `art/character_design/anim/timing.json`（只追加）：游戏里立起来约 0.3 秒、两边倒下约 0.6 秒，翻页建议约 0.3 秒；程序按用户调好的节奏播放（合上时倒放），所以每帧时长只是参考，**帧与帧之间的动作要均匀** |
