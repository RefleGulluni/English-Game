## 2. 它是谁

> **Body ended. Structure refuses to end.**
> 身体已经死去，但“结构”仍坚持维持自身。

- **不是普通骷髅兵**，不要通用暗黑奇幻 / 中世纪骷髅战士的样子（主角第一版就是因为“太通用、太中世纪”被否决的）。
- 视觉关键词（World Bible）：**下葬用的绳索、裹尸布、铁钉、黑色缝线、不自然的骨间连接**。骨头之间像被某种结构**强行牵住**，而不是靠关节自然连着。
- 以后动作上会是：肩膀延迟、骨盆先动、手臂轻微错位、骨件像被牵引。设计时让各块骨件和牵连物**看得清楚**，方便以后逐帧动画；但**不是**骨骼拆件 / 纸偶结构（旧的 `art/enemies/skeleton_parts/` 已作废，不要参考）。
- 拿不拿武器、穿多少裹尸布，由你们提方案。

## 3. 必须同时设计：Bone Remains（骨堆）

这是骷髅最重要的玩法：被打到 0 HP 后**不会消失**，而是散成一堆骨头（Bone Remains）。玩家不处理的话，3 回合后它会**重新拼起来**。

所以每个方向都要同时画：

1. **站立形态**：正对镜头。
2. **骨堆形态**：同一具骷髅散落在地上的样子。

要求：

- 骨堆必须一眼认得出**是同一具骷髅**：同样的绳索、布、钉子都散在里面。
- 骨堆要让玩家觉得**“它还没死透，还会起来”**：比如绳索仍然连着几块骨头、有一块还在微微立着。这一点用造型表达，**不要用发光**。
- 骨堆是贴地的矮物件，大小参考：宽 48～72 px、高 20～36 px。

## 4. 像素规格

| 项目 | 规格 |
|---|---|
| 画布 | 站立 96×96，透明背景；脚底锚点 (48, 96)，最低的不透明像素在 y=95 |
| 身高 | 接近主角：头顶到脚底 84～96 px（Art Bible §21.4：“Skeleton 接近主角”） |
| 视角 | 与主角一致的 3/4 俯视世界；站立形态**正对镜头**（同 `hero_B1_front_straight.png`） |
| 光源 | 左上 |
| 像素 | 真像素：无半透明、无抗锯齿、无渐变；AI 生成的先整理（网格 → 调色板 → 边缘）再交付 |
| 调色板 | 与墓园物件同一套颜色（从北极星图取）；需要新颜色时在 QA 里列出来并说明原因 |
| 描边 | **不加**整圈描边（与主角一致） |
| 阴影 | **不画地面投影**，接触阴影由 Godot 处理 |
| 禁用颜色 | **饱和的青蓝色是语言层专用**（Word Sigil、Lexicon、True Words），骷髅身上一点都不能有。“结构”的力量用黑线、绳索、钉子表现，不要发光 |
| 禁用效果 | 不要 glitch、撕裂、像素错位之类的效果（Fracture 永远不破坏像素网格） |

可读性要求：在墓地湿泥地面上、按游戏里的 2 倍大小看，要和主角**轮廓明显不同**，并且站在泥地上不会糊成一团（骨头的浅色和泥地的暗色要拉开）。
