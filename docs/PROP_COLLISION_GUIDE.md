# 怎么改物件的碰撞（给用户的说明）

建立：2026-10-25（Claude）。决定：Decision Log D-034。
用户在 Obsidian 里也存了一份：`教程/Godot改遮挡.md`。两份保持一致，改动时同步。

每件墓园物件都是一块“积木”，放在 `scenes/props/cemetery/`，一件一个文件（例如 `tombstone_flat_01.tscn`）。积木里装着：

| 积木里的东西 | 名字 | 谁管 |
|---|---|---|
| 底座贴花（泥、草） | `Base` | 美术，不要动 |
| 物件本体 | `Sprite` | 美术，不要动 |
| 碰撞 | `Body` → `Shape` | **你来调** |
| 主角走到后面变半透明 | 程序自动处理 | Claude |

你改的碰撞会跟着积木走：试走房间、以后的正式房间、你自己拖进去的地图，用的都是同一份。

---

## 1. 先记住一条规矩：只框“踩在地上的那一块”

我们是斜着往下看的视角。碰撞管的是**脚能不能站在这里**，不是“图片有多大”。

- **墓碑、墙、柱子**：只框底部贴着地面的那一条（大约 8～14 像素高）。主角可以绕到墓碑后面，这时墓碑会自动变半透明。
  如果把整块墓碑都框住，主角走到碑后面就会被一堵看不见的墙挡住。
- **墓穴、棺盖**：它们平躺在地上，框住整块（墓穴要框住坑，不让主角走进去）。
- **蜡烛、花瓶、碎石堆、墓灯、平躺墓板**：不挡路，碰撞是**关着的**。想让它挡路，把它打开即可（见第 4 步）。

积木的**原点**（画面里十字线交叉的那个点）就是物件“脚”的位置，碰撞框应该贴着这个点附近。

## 2. 打开一块积木

1. 打开 Godot，在项目列表里双击 **English-Game**。
2. 左下角的“文件系统”面板里，依次点开 `scenes` → `props` → `cemetery`。
3. **双击**想改的那件，例如 `tombstone_flat_01.tscn`。中间的画面会显示这块墓碑。
4. 看不清就把鼠标放在画面上**滚轮放大**；按住**鼠标中键**（或空格 + 左键）拖动画面。

## 3. 改方形的碰撞框（大部分物件）

1. 左上角的“场景”面板里，点开 `Body`，点一下下面的 **`Shape`**。
2. 画面里会出现一个**淡蓝色的方框**，边上和角上有几个**小圆点**。
3. **拖小圆点**：改变方框的大小。
4. **移动方框**：在右边的“检查器”面板里改 `Transform` → `Position` 的数字（x 往右为正，y 往下为正）。直接在画面里拖方框也可以，但容易把它拖歪，改数字更准。
5. 改完按 **Cmd + S** 保存。

## 4. 打开 / 关闭碰撞

选中 `Shape`，在右边“检查器”里找到 **`Disabled`（禁用）**：

- 勾上：不挡路（蜡烛、花瓶等默认是勾上的）；
- 取消勾选：挡路。

## 5. 改多边形的碰撞（墓穴、棺盖）

`open_grave_01` 和 `grave_lid_01` 是斜放的长方形，用的是**多边形**：画面里是一圈连起来的点。

1. 同样选中 `Body` → `Shape`。
2. **拖动一个点**：移动这个角。
3. **Ctrl + 点击线段**：在这条边上加一个新点。
4. **右键点一个点**：删掉这个点。
5. Cmd + S 保存。

## 6. 把方框换成多边形

方框不能直接“变成”多边形，做法是：**新建一个多边形，再删掉旧方框**。

**第一步：新建多边形**

1. 在左上角“场景”面板里，**右键点 `Body`** → 选 **“添加子节点”**（Add Child Node）。也可以选中 `Body` 后按 **Cmd + A**。
2. 弹出的窗口上方有个搜索框，输入 **`CollisionPolygon2D`**，选中它，点右下角 **“创建”**。
3. `Body` 下面会多出一个 `CollisionPolygon2D`。双击它的名字可以改名，例如改成 `Polygon`（不改也没关系）。

**第二步：画出多边形**

1. 选中新建的 `CollisionPolygon2D`，画面上方的工具栏会出现几个画多边形的小按钮（铅笔一类的图标）。
2. 选**第一个“创建点”的按钮**，在画面里**一下一下点击**，每点一下就放一个角。顺着物件的脚围一圈。
3. 最后**点回第一个点**，多边形就闭合了，里面会填上淡蓝色。
4. 画完后切到**“编辑点”的按钮**，就可以照第 5 节的方法微调：拖点、Ctrl + 点击线段加点、右键删点。

**第三步：删掉旧方框**

1. 在“场景”面板里**右键点旧的 `Shape`** → **“删除节点”**（Delete Node），或选中后按 **Delete**（Mac 上是 **Fn + Delete** 或 Cmd + Backspace）。
2. 不想删也可以：选中它，在右边“检查器”里勾上 **`Disabled`**，它就不起作用了。
3. Cmd + S 保存。

> 小提示：多边形的点**不要交叉**（像打了个结的绳子），否则碰撞会出错。顺着一个方向（顺时针或逆时针）点一圈就不会交叉。

## 7. 再加一个碰撞框

有的物件需要两块碰撞，例如一边高一边低的断墙、或者带着落地断块的墓碑。**一个 `Body` 下面可以放好几个碰撞框**，它们合在一起挡路。

**方法 A：复制现有的方框（最快）**

1. 选中 `Shape`，按 **Cmd + D**（复制），下面会多出一个 `Shape2`。
2. ⚠️ **重要**：选中 `Shape2`，在右边“检查器”里找到 **`Shape`** 那一栏（显示着 RectangleShape2D），**点它右边的小下拉箭头 → 选“唯一化”（Make Unique）**。
   不做这一步的话，两个方框其实共用同一个尺寸：改一个，另一个也跟着变。
3. 改 `Shape2` 的 `Transform` → `Position` 把它挪到新位置，再拖小圆点改大小。
4. Cmd + S 保存。

**方法 B：新建一个方框**

1. 右键点 `Body` → “添加子节点” → 搜索 **`CollisionShape2D`** → 创建。
2. 新建的碰撞框是空的，画面里还看不到。选中它，在右边“检查器”里找到 **`Shape`**，点右边写着 **“<空>”**（empty）的地方 → 选 **“新建 RectangleShape2D”**。
   （想要圆形就选 `CircleShape2D`，胶囊形选 `CapsuleShape2D`。）
3. 画面里出现方框后，照第 3 节拖小圆点、改位置。
4. Cmd + S 保存。

**也可以再加一个多边形**：照第 6 节的第一、二步，再建一个 `CollisionPolygon2D` 就行。

> 记住：所有碰撞框都要放在 **`Body` 下面**（在“场景”面板里，它们要缩进在 `Body` 的下一层）。放在别的地方不起作用。如果不小心放错了位置，可以用鼠标把它**拖到 `Body` 上**。

## 8. 进游戏验证

1. 在“文件系统”里双击 `scenes/prototypes/props_v3/props_v3_room.tscn`（试走房间）。
2. 按 **Cmd + R**（运行当前场景）。
3. 想看见碰撞框：先在顶部菜单 **调试（Debug）** 里勾上 **“显示碰撞区域”（Visible Collision Shapes）**，再运行。游戏里每个碰撞框都会显示成半透明的蓝色。
4. 用 WASD 走一走，看哪里卡得别扭，回到第 2 步继续改。

## 9. 不要做的事

- **不要动 `Sprite` 和 `Base`**：不要拖动、缩放、旋转它们。像素画一缩放就糊，一偏就不在整像素上了。
- **不要移动整块积木的根节点**（最上面那一行）的位置。
- **不要删掉 `Body`**。碰撞框（`Shape`、多边形）可以删、可以加，但至少留一个；整件不想挡路，就用第 4 步把它关掉。
- **不要缩放碰撞框节点**（检查器里的 `Transform` → `Scale` 保持 1）：要改大小就拖小圆点或拖点。
- 改完告诉 Claude 一声，Claude 会检查并提交。积木生成工具不会覆盖已经存在的积木，所以你改过的碰撞不会被冲掉。

## 给 Claude（技术说明）

- 积木由 `scripts/tools/bake_cemetery_props.gd` 从 `art/cemetery_v3/props/props_manifest.json` 生成；已存在的积木跳过，`-- --force=<名字>` 重建单件（会丢掉手调的碰撞，先问用户）。新素材入库后：`--import` → 运行该工具。
- 脚本 `scripts/world/v3/cemetery_prop.gd`（`CemeteryProp`）：根节点 = 脚的位置 = Y 排序点；`ground_gap` = PNG 底部透明行数（布局数据里的坐标是 PNG 原点，摆放时减去它）；`flat` = 平躺物件，和底座一起画在 z = -5，永远不挡人。
- 半透明判断：主角在物件后面（脚的 y 更小），且主角身上的 8 个采样点落在物件**真实不透明的像素**上，而不是整张图片的方框里。
- `CemeteryRoom` 有同名积木就用积木，没有才走旧的“图片 + 代码生成碰撞”。图层：地面板 z = -10，底座和枯草 z = -5，物件和角色 z = 0（Y 排序）。
