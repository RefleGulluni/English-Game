## 1. 这一批为什么做

现在墓碑只有 3 件（`tombstone_upright_01`、`tombstone_upright_02`、`tombstone_cross_01`）。一个场景摆十几块墓碑就会满眼重复。多样性的分工（制作手册 §9）：

| 变化 | 谁做 |
|---|---|
| **形状**（不同的墓碑） | 你们，本批 |
| **状态**（歪斜、断裂） | 你们，本批。**像素画不能靠旋转来“歪”，必须单独画** |
| 换石头颜色（调色板替换） | Claude 在 Godot 里做，**你们不用画颜色变体** |
| 下沉深浅 | Claude 在 Godot 里做 |
| 摆放规则、穿插小物件 | Claude 摆；小物件由你们本批画 |

## 3. 规则

- **和第一批同一块墓园、同一个石匠**：石头颜色、苔藓、地衣、雨痕、深色收边，都对照 `tombstone_upright_01.png`、`tombstone_cross_01.png`。这批不需要新的石头颜色。
- **精致程度（下限）**：和主角并排 6 倍看不显得简单；目标是颜色 30～50、换色比例不低于 80%（主角 44 色 / 88%，第一批墓碑 83～86%）。小物件面积小，数字仅供参考，以眼睛看为准。
- **上限**：每一小块颜色都说得出是什么；不能为了数字加随机杂点。
- **碑上的刻字只画成看不清的刻痕**，不写可读的字母或单词（可读的英文属于语言层，不能出现在世界物件上）。
- 不画地面投影；不加整圈描边；没有饱和青蓝；不镜像、不旋转。
- 新形状是新生成 → 逐格还原；状态件以底子的像素为基础改画，必要时可以对照底子重新生成局部，再还原整理。
- 画布尺寸、原点、可见高写进 `props_manifest.json`，**不要改动已通过的物件**。
