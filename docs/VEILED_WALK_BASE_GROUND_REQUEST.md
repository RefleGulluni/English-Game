## 0. 背景

- 一局分 4 个区域：外墓园（第 1～2 层）→ **雾中墓径**（第 3～4 层）→ 黑雾深处 → 哀悼礼拜堂（Boss）。
- 雾中墓径：**雾更浓、墓更密、更潮湿、更安静**，“很久没人走过”。你们上一件交付的厚苔藓地 `moss_texture_01` 第二版已经通过（D-077），谢谢，平软连续得很好。
- 现在雾中墓径的房间还在**借用外墓园的底子** `ground/base/ground_base_01/02.png`，只是在游戏里整体压了一层冷蓝。看起来就是“外墓园调暗了”，不像一个新地方。这次给它一套自己的底子。
- 地面分层（已定型）：**大块底子**（铺满整个房间，只含平的信息）→ 用户刷的过渡层（泥路 / 枯草 / 苔藓 / 石板）→ 贴花。底子是最下面、面积最大的一层，所以**最安静**。

## 2. 数字（以下全部在“没有任何游戏调色”的原图上量）

- **平均色约 (58～63, 61～66, 60～65)**：外墓园底子是 (70,70,60)，这次**更暗、去掉暖黄、偏冷灰**；但不能是蓝色，饱和度要低。
- 必须和苔藓地 `moss_texture_01`（平均 (59,69,55)，偏绿）**分得开**：底子偏冷灰，苔藓偏灰绿。
- **亮度标准差约 8～10**（外墓园底子 9.5、泥路 8.2）。底子要安静。
- 颜色约 30～40 色。
- 主角风衣约 (90,72,52)，站在上面要清楚。
- 没有饱和青蓝（那是“语言”专用色）。
- **看不出单位**：没有一个一个的石子、鳞片、鼓包；深浅靠大小不一的斑块慢慢过渡。平铺 3×3 眯眼看，如果能指出“这一块和那一块是同一个”，或者看出一排排、一格格的规律，就是没过关。

## 4. 2026-10-30 验收：第一版未通过；换做法，请以外墓园底子为底子改

谢谢你们在发现重复时自己停下、把证据标清楚，停对了。数字（平均色、亮度标准差、颜色数、首尾相接、01/02 外圈一致）全部达标，这些检查做法保留。

**游戏里的样子**：Claude 把两块底子铺进雾中墓径的房间，和外墓园底子在**同一个房间、同样的调色**下并排比（只换底子）。外墓园底子像软软的湿泥；新底子满是**斜向的条纹和碎块**，整片读成灰色迷彩布 / 柏油路面，不像泥地；混铺的块状节奏也看得出来。用户同意不通过。

**原因主要在做法**：整张重新生成，质感就会跟着生成图走，很难再回到外墓园底子那种已经被验证过的软泥质感。制作手册的规则是“同家族的零件以已有零件为底子改出来”，这一次应该照它做。

### 新做法（取代第 1 节“它是什么”的生成方式；数字要求不变）

1. **从已通过的 `ground_base_01.png`、`ground_base_02.png` 出发**（原生 224×128，不重新生成整张）。它们本来就首尾相接、外圈互相一致，**保留这个结构**。
2. **换一套颜色（一对一的色表替换）**：把它的颜色整体换成更暗、更冷、更湿的一套。暖黄 / 橙褐的泥块换成深褐灰或冷灰，不留暖黄；整体平均色落在第 2 节的 **(58～63, 61～66, 60～65)**，亮度标准差 **8～10**。**不是在上面罩一层蓝**：深的更深、浅的稍冷，明暗关系保持泥的感觉。
3. **加上“雾中墓径自己的东西”**（只用新色表里的颜色，对比都很低）：
   - 几片**大小不一、边缘不规则的湿暗区**（约 20～60 px，比周围暗一点点），像吸饱了水的低洼；
   - 几片**很淡的潮光**（比周围亮一点点，不能像水面）；
   - 零星**泡烂的深色落叶碎屑**（2～4 px 的小斑，不画完整叶子）。
   - 01 和 02 加的位置、形状要不同，这样两块混铺才不重复。
   - **不要**画成一个一个的单位（鳞片、石子、鼓包）、不要斜向条纹、不要积水和草。
4. 加的东西**不要碰到最外 8 px**，这样首尾相接和 01/02 外圈一致就自动保住了；如果一定要跨边，用平移半张的办法修十字。

**自查**（比上次多一条）：
- 01/02 随机混铺 3×3，眯眼看，指不出“同一块”、看不出斜纹和块状节奏；
- **和外墓园底子并排**：要看得出是同一种泥（同一个家族），但这边明显更湿、更暗、更冷，像“走进了雾里”；
- 和苔藓地 `moss_texture_01` 仍然分得开（苔藓偏灰绿，底子偏冷灰）。

交付同第 3 节，**覆盖** `veiled_base_01.png`、`_02.png`（第一版已有你们的恢复包 `backups/veiled_before_visual_stop.zip`，不用再备份），QC 图换新，另加 `qc/veiled_base_vs_outer_2x.png`（外墓园底子和新底子各铺半屏并排，2 倍）。完成后停下，等用户验收。
